# Desktop Agent GUI — Agent 桌面编排

强大的技术值得一个尊重你时间的界面。把 CLI agent 编排变成
可视化桌面体验——无需终端。

## 何时用

- 不想碰终端/YAML/环境变量，想图形化用 agent
- 桌面统一管理多个 agent、频道、定时任务
- 日常监控/工作流自动化（结果投递到通知频道）

## 1. 核心特性

- **零配置门槛**：图形向导完成全部设置
- **智能聊天**：流式 Markdown + 语法高亮、CJK 感知解析、
  `@agent` 直路由、inline `/skill` 卡片、工作区优先会话、
  Markdown/.docx/.pptx/HTML 只读预览
- **多频道管理**：独立 AI 频道、多账号、按账号绑定 agent、
  默认账号切换
- **Cron 自动化**：一次性/循环调度，技能插入定时 prompt，
  结果投递到外部频道
- **可扩展技能系统**：本地管理技能（不依赖 Gateway），
  多来源发现，内置文档处理技能（pdf/xlsx/docx/pptx）
- **安全提供商集成**：凭证存系统钥匙串、OAuth、自定义提供商、
  图像生成端点、兼容回退

## 2. 典型场景

- 个人 AI 助手（问答/起草邮件/总结文档）
- 自动监控（新闻/价格/事件，投递到通知频道）
- 开发者生产力（代码评审/文档生成）
- 工作流自动化（多技能链成可视化流水线）
