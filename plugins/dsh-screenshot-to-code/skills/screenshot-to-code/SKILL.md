# Screenshot To Code — 截图转代码

把截图/设计稿变成干净可编辑的前端代码（HTML/Tailwind/React/Vue）。

## 何时用

- "把这个截图做成网页"
- 从设计稿/现有 UI 还原为代码
- 快速原型（有视觉参考）

## 1. 分析阶段

- 识别**布局结构**：区域/栅格/间距节奏
- 识别**组件**：按钮/表单/卡片/导航（拆分可复用）
- 提取**设计 token**：颜色/字体/圆角/阴影/尺寸
- 注意状态与交互暗示（hover/选中/加载）

## 2. 生成阶段

- 技术栈按目标（HTML/Tailwind/React）
- 组件化输出（可维护而非一坨）
- 语义化结构与可访问性（aria/alt/焦点）

## 3. 验证迭代循环（核心）

`生成 → 渲染截图 → 与目标对比 → 修正 → 重复`

- **渲染自己生成的代码**再截图对比（不靠目测）
- 逐项核对：布局对齐/间距/色彩/字体/圆角
- 一次修一个偏差（可对比）
- 响应式：多断点验证

## 4. 交付

- 干净可编辑代码（非一次性输出）
- 交互与状态补全（截图没有的部分合理实现）
- 说明假设（截图模糊处/缺失资源）

## 5. 自查清单

- [ ] 布局/组件/token 分析完整
- [ ] 组件化输出、语义化 + 可访问性
- [ ] 渲染对比逐项核对
- [ ] 一次修一个偏差
- [ ] 响应式多断点验证
- [ ] 假设已说明

## 边界

- 复杂截图一次难到位：迭代验证循环是质量关键。
- 与 web-clone（提取字体/色彩/动效规格）互补：本技能是完整转换工作流。
