# PDF Processing — PDF 处理

用 Python 库与命令行工具完成 PDF 各种操作。

## 何时用

- 读取/提取 PDF 文本与表格
- 合并/拆分多个 PDF
- 旋转页面、加水印
- 创建新 PDF
- 填 PDF 表单
- 加密/解密 PDF
- 提取图片
- 扫描件 OCR（可搜索化）

## 1. 基础操作（pypdf）

- 读取：`PdfReader` → 页数/逐页提取文本
- 写入：`PdfWriter` → 合并/拆分/旋转/加水印
- 加密解密：权限设置与密码

## 2. 表格与数据提取

- 文本提取不理想时用表格提取库（pdfplumber/camelot 类）
- 结构化输出：表格转 CSV/DataFrame
- 扫描件：OCR（tesseract 类）转可搜索文本

## 3. 创建与编辑

- 创建新 PDF：reportlab 类（文本/图形/布局）
- 表单：读取字段结构 → 填写 → 保存（FORMS 流程）
- 提取图片：从页面提取嵌入图像

## 4. 纪律

- 保留原文件备份（操作可能不可逆）
- 输出验证：提取后抽查内容完整性
- 敏感文档注意权限与加密

## 5. 自查清单

- [ ] 操作类型选对库（pypdf/pdfplumber/reportlab/OCR）
- [ ] 原文件已备份
- [ ] 提取结果抽查验证
- [ ] 合并/拆分页序正确
- [ ] 表单填写保存后验证
- [ ] 敏感文档已加密

## 边界

- 复杂版式 PDF 提取可能不完美：视觉检查结果。
- 工具特性差异大，按所选库文档。
