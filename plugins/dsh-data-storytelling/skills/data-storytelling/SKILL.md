# Data Storytelling — 数据叙事

把原始数据变成**推动决策、激发行动**的故事。数据只是事实，叙事赋予
意义与行动指向。

## 何时用

- 向高管展示分析
- 季度经营回顾
- 投资人演示
- 写数据驱动报告
- 向非技术受众传达洞察
- 基于数据提建议

## 1. 从问题出发（先想清楚讲什么）

- 受众是谁？他们要做什么决策？
- 核心信息是什么？（一句话：数据说明什么、所以应该做什么）
- 讲"变化与因果"，不是罗列数字。

## 2. 叙事结构（SCQA）

- **Situation 背景**：现状是什么。
- **Complication 冲突**：出了什么问题/机会。
- **Question 问题**：因此要回答什么。
- **Answer 答案**：数据说明什么 → 建议行动。

## 3. 可视化选择

| 想表达 | 用什么图 |
|---|---|
| 对比 | 柱状图（分组/堆叠） |
| 趋势 | 折线图 |
| 占比 | 饼图（≤5 类）或堆叠条 |
| 分布 | 直方图/箱线图 |
| 关系 | 散点图 |
| 排名 | 水平条形图 |

- 一图一事：每张图只讲一个洞察。
- 标题即结论（"Q2 留存提升 8%，因新用户引导改版"），不写"销售趋势图"。
- 标注重点：高亮关键数据点，引导视线。

## 4. 增强可信度

- 标注数据来源与时间范围。
- 诚实呈现不确定性（样本、误差、对比基线）。
- 呈现反面数据（不做选择性呈现，保持可信）。
- 结论与数据对应（每个结论都有数据支撑）。

## 5. 交付格式

```markdown
## 数据叙事：<标题>

**核心信息**：<一句话>

**背景**（Situation）：
**问题/机会**（Complication）：
**关键发现**（带图表+数据）：
1. …
2. …
**建议**（Answer）：
- …

**数据来源与说明**：…
```

## 边界

- 数据叙事不编造故事：所有叙事基于真实数据，标注假设。
- 与 ppt-creator 配合（排版呈现），与 data-quality 配合（数据可信前提）。
