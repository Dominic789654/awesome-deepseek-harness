# Better Interface — 界面质量技能系列

一组帮你做出好界面的技能：UI、排版、颜色、可访问性、布局、
产品写作——六个维度 + 三个元技能。

## 何时用

- 打磨界面细节（让 UI 感觉 polished）
- 一版 UI 想要多个候选变体实测
- 好奇某个效果怎么实现的（逆向）
- 交付前对改动做全维度评审

## 1. 六大维度技能

- **better-ui** — 设计工程细节：圆角、阴影、动画、微交互
- **better-typography** — 字体选择与配对、字号阶梯、间距、换行截断
- **better-colors** — 色彩系统：构建命名调色板、有意义的用色、对比度、主题
- **better-accessibility** — 焦点态、键盘支持、ARIA、表单、屏幕阅读器、命中区、动效
- **better-layout** — 布局结构、分组、对齐、阅读顺序、渐进披露、自适应断点
- **better-writing** — UX 文案：按钮标签、错误、设置、空状态

## 2. 元技能

- **better-interface** — 跨学科界面评审，协调下面所有技能
- **interface-review** — 用户主动触发：对未提交改动/当前分支/PR
  跑全维度评审（不会自己启动）
- **variant** — 一版 UI 生成几个**真正不同**的版本放在选择器后面，
  在真实页面里切换，推广胜者
- **explain-interface** — 给 URL 或截图，点名好奇的东西，
  找出效果背后的层次，展示最小重建方式

## 3. 自查清单

- [ ] 六维度过一遍（UI/排版/颜色/可访问性/布局/写作）
- [ ] 界面评审按需触发（不自动打断）
- [ ] 变体实测再推广（variant）
- [ ] 效果逆向最小重建（explain-interface）
- [ ] 对比度/焦点态/键盘支持达标

## 边界

- 面向界面打磨；品牌方向/整体设计系统见专门技能。
- variant 是实测驱动——数据说了算，不凭喜好。
