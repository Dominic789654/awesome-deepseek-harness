# dsh-html-ppt

DSH（DeepSeek Harness）技能插件：**HTML PPT Studio**。

纯静态 HTML/CSS/JS 制作专业演示：36 主题（token 驱动换肤）、31 页面布局、47 动画（27 CSS + 20 canvas FX）、15 全套模板、演讲者模式（S 键四磁吸卡 + 逐字稿 + 计时器，BroadcastChannel 同步）、键盘导航与单页预览。零构建步骤。受 [lewislulu/html-ppt-skill](https://github.com/lewislulu/html-ppt-skill)（8k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-html-ppt
```

## 触发方式

描述中包含"HTML 演示 / 网页 slides / 技术分享 deck / 演讲者模式 / 小红书图文 / 动画特效 PPT"等关键词时自动触发。

## 能力

- 36 主题 × 31 布局 × 47 动画 × 15 全套模板
- 演讲者模式（磁吸卡 + 逐字稿 + 计时器）
- token 驱动设计系统（换 link 整体换肤）
- 键盘导航 / 总览 / 主题循环
- 中英一等公民排版（Noto SC 预导入）
- 零构建、单 HTML 交付
