# dsh-observability-tools

DSH（DeepSeek Harness）技能插件：**可观测性工具实操**。

Prometheus 配置（命名/采集/Recording Rules/告警）、Grafana 仪表盘（RED/USE 方法、信息层级、SLO 面板）、OpenTelemetry 分布式追踪（上下文传播/采样）。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-observability-tools
```

## 触发方式

描述中包含"Prometheus / Grafana / 监控配置 / 告警规则 / 分布式追踪 / OpenTelemetry / 可观测性工具"等关键词时自动触发。

## 能力

- Prometheus 采集/服务发现/Recording Rules
- Grafana 信息层级 + RED/USE 面板
- 追踪上下文传播与采样策略
- 三件套关联排障
