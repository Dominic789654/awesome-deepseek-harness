# 交付前自查清单

## 层级与布局
- [ ] 页面有明确主角（主 CTA / 主内容），视觉第一眼能定位
- [ ] 标题-正文-辅助信息三档层级清晰
- [ ] 网格对齐，留白充分，无元素"挤在一起"
- [ ] 长页面有滚动节奏（分区、间距、视觉停顿）

## 配色与对比度
- [ ] 主色 ≤ 2 个（含强调色），中性色成体系
- [ ] 正文对比度 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1
- [ ] 状态不只用颜色区分（配合图标/文字）

## 字体与间距
- [ ] 正文 14-16px，行高 1.5-1.6，中文系统字体回退
- [ ] 间距用 4px/8px 基准系统，全局一致

## 组件与交互状态
- [ ] 默认/hover/focus/active/disabled/错误 状态齐全
- [ ] 表单有 label、校验与错误提示
- [ ] 空状态 / 加载状态 / 错误状态已设计

## 响应式
- [ ] 320px / 768px / 1280px 三档检查
- [ ] 触控目标 ≥ 44px（移动端）

## 无障碍
- [ ] 语义化 HTML，单一 h1，标题层级不跳级
- [ ] 图片有 alt；图标按钮有 aria-label
- [ ] 键盘可完整操作，focus ring 可见
- [ ] 不禁止缩放；动效尊重 prefers-reduced-motion
