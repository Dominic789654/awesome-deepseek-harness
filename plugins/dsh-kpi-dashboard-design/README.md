# dsh-kpi-dashboard-design

DSH（DeepSeek Harness）技能插件：**KPI 仪表盘设计**。

SMART 指标选型、战略-战术-运营三层框架、仪表盘层级（高管摘要/部门视图/钻取）、可视化最佳实践（5-7 个 KPI/上下文/颜色规范）、指标口径治理与实时监控模式。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-kpi-dashboard-design
```

## 触发方式

描述中包含"KPI / 仪表盘 / 指标看板 / 监控大屏 / 高管面板 / 指标口径 / 数据看板设计"等关键词时自动触发。

## 能力

- SMART KPI 与三层框架
- 仪表盘层级与钻取设计
- 可视化最佳实践清单
- 指标口径治理与实时监控模式
