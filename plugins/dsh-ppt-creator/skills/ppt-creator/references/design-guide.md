# PPT 视觉设计指南与自查清单

## 设计原则

- **一致性**：全局 1 个主色 + 1 个强调色 + 中性色（灰/白/黑）；所有页面
  同字体族（中文：系统黑体/思源黑体回退）、同标题字号、同间距基准（8px 体系）。
- **层级**：页面标题 > 小节标题 > 正文。用字号+字重区分，不要用 5 种颜色。
- **克制**：每页视觉焦点 ≤ 1 个；装饰元素（图标/色块）服务于内容，不喧宾夺主。
- **对比度**：正文与背景对比 ≥ 4.5:1；不要用浅灰字配白底。
- **留白**：页边距一致（≥ 48px）；正文行高 1.4-1.6；段间留空隙。

## 页面模板（16:9，960×540 设计稿基准）

- **封面页**：大标题（40-48px）+ 副标题（18-22px）+ 日期/汇报人。
- **目录页**：3-5 个章节，编号 + 短标题。
- **章节页**：章节名大字 + 页码/进度。
- **内容页**：标题（24-28px）+ 要点（16-18px，每页 3-6 条）+ 可选图表。
- **总结页**：核心结论 3 条 + 下一步行动。

## 图表规范

- 柱状图比饼图更适合对比；折线图适合趋势。
- 图表必须有标题与单位；坐标轴标签可读。
- 不要用 3D 效果和多余网格线。

## 自查清单（出稿前逐项过）

- [ ] 无错别字、无残留占位符（"TODO""XX 公司"等）
- [ ] 每页标题/正文无溢出（HTML 稿检查文字是否超出视口）
- [ ] 全局字号、配色、间距统一
- [ ] 正文与背景对比度达标
- [ ] 页数与大纲一致（±1）
- [ ] 数据图表有标题和单位
- [ ] 封面/目录/章节/总结页齐全（按需）
