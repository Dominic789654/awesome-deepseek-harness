# PPT Creator — 中文演示文稿生成

把内容做成专业、美观、可用的中文 PPT。不依赖任何第三方模板库，纯靠
结构化流程 + 设计原则 + agent 的排版能力出稿。

## 工作流

1. **澄清需求**（信息不足时先问，一次问清）：
   - 场景：工作汇报 / 年终总结 / 述职竞聘 / 项目答辩 / 教学课件 / 商务提案 / 读书分享
   - 时长或页数：10 分钟≈10-12 页，20 分钟≈15-20 页
   - 受众与风格：领导汇报（克制稳重）/ 评审（逻辑严密）/ 教学（清晰渐进）…
   - 已有素材：大纲 / 文档 / 数据，还是从零写？

2. **搭大纲**：先给完整大纲让用户确认（骨架对了再填充）。
   - 汇报类：背景→进展/成果→问题→下一步
   - 提案类：痛点→方案→价值→落地计划
   - 教学类：引入→概念→示例→练习→总结
   - 每页只讲一件事，一页一个标题 + 支撑要点。

3. **视觉设计**（遵循 [references/design-guide.md](references/design-guide.md)）：
   - 统一风格：主色 1 个 + 中性色 + 强调色 1 个；每页同字体、同间距体系。
   - 16:9 版式；标题层级清晰；正文 ≤ 6 行/页；要点用短句。
   - 数据用图：优先原生图表（柱状/折线/饼），不放整段数据表格。
   - 留白 > 填充：宁可一页少内容，不要塞满。

4. **出稿**（二选一，问用户要哪种）：
   - **HTML 稿**（默认，零依赖）：输出一个自包含 HTML 文件，每页一个
     `<section>`，16:9 比例，打印/浏览器全屏演示可用。写完自查。
   - **PPTX 稿**（需环境支持）：若环境有 python + python-pptx，写脚本生成
     原生 .pptx（标题 + 正文占位符、统一主题色）；没有则说明并回退 HTML。

5. **自查**（[references/design-guide.md](references/design-guide.md) 末尾清单）：
   无错别字、无溢出、字号一致、配色对比度达标、页数符合预期。

## 输出

- 先给大纲 → 确认后出稿 → 出稿后给自查结果与"哪里还能调"的说明。
- 交付 HTML 时给出文件路径；交付 PPTX 时给出脚本与产出文件路径。

## 边界

- 不做用户没要求的动画/特效；如需强调用简单淡入即可。
- 不编造数据；数据缺失时用占位并标注"待补充"。
