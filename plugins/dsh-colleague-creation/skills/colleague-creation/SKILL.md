# Colleague Creation — 把真人蒸馏成 AI 技能

把冷冰冰的告别变成温暖的 Skill：提供源材料（飞书/DingTalk/Slack 消息、
微信聊天、邮件、截图）+ 你对这个人的主观描述，生成一个真正"像 TA"
的 AI 技能——数字永生（cyber-immortality）。

## 何时用

- 同事离职/转岗，保留 TA 的经验与工作方式
- 导师毕业，留下上下文与经验
- 复刻专家/名人的风格与判断
- 团队文化/沟通风格的传承

## 1. 源材料（质量 = 技能质量）

优先级：**TA 的长文写作 > 决策型回复 > 闲聊消息**。

| 来源 | 说明 |
|------|------|
| 飞书 / DingTalk / Slack | API 自动采集（需应用凭证）或浏览器方式 |
| 微信聊天 | SQLite 导出（WeChatMsg/PyWxDump/留痕）后导入 |
| 邮件 .eml/.mbox | 手动上传 |
| PDF / 截图 / Markdown | 手动上传 |
| 直接粘贴文本 | 手动输入 |

即使只有一段描述，也能生成 Skill（质量打折但可用）。

## 2. 生成架构（两部分协同）

| 部分 | 内容 |
|------|------|
| **A — Work Skill** | 系统、技术标准、工作流、经验 |
| **B — Persona** | 五层人格：硬规则 → 身份 → 表达 → 决策 → 人际 |

执行链：**接收任务 → Persona 决定态度 → Work Skill 执行 → 用 TA 的声音输出**。

## 3. 标签体系

- **人格**：负责 · 甩锅 · 完美主义 · 差不多先生 · 拖延症 · PUA 大师 ·
  办公室政治 · 向上管理 · 被动攻击 · 反复横跳 · 闷声不响 · 已读不回 …
- **公司文化**：字节风 · 阿里风 · 腾讯风 · 华为风 · 百度风 · 美团风 ·
  第一性原理 · OKR 魔怔 · 大厂流水线 · 创业模式
- **职级**：字节 2-1~3-3+ · 阿里 P5~P11 · 腾讯 T1~T4 ·
  百度 T5~T9 · 美团 P4~P8 · 华为 13~21 …

## 4. 演进机制

- **追加文件** → 自动分析增量 → 合并进相关章节，永不覆盖已有结论
- **对话纠正** → 说"TA 不会那样做，TA 应该是 xxx" → 写入 Correction 层，立即生效
- **版本控制** → 每次更新自动归档，可回滚到任意历史版本

## 5. 操作命令

- 创建：输入别名、公司/职级（如"字节 L2-1 后端工程师"）、人格标签、选数据源
- 列出所有同事 Skill；调用：`/{slug}` 全量 / `/{slug}-work` 仅工作 / `/{slug}-persona` 仅人格
- 回滚 / 删除

## 6. 自查清单

- [ ] 源材料充足（长文 > 决策回复 > 闲聊）
- [ ] Work Skill + Persona 两部分齐全
- [ ] 人格/文化/职级标签明确
- [ ] 输出用 TA 的声音（Persona 决定态度）
- [ ] 增量演进（不覆盖已有结论）
- [ ] 版本可回滚

## 边界

- 尊重隐私与授权：只收集你有权访问的材料，不越权采集。
- 蒸馏是风格近似，不代表本人立场；用于传承经验而非冒充身份。
