# Doc Compiled Skills — 文档预编译成技能

文档不是新发明——它们已包含结构化模式、工作流与决策逻辑。
把官方文档预编译成可执行技能，而不是让 agent 每次 RAG 检索。

## 何时用

- 把官方文档（API/配置/故障排查/安全合规）变成 agent 技能
- 替代"每次 RAG 检索原始文本"的低效
- 团队共享"预编译知识"而非每人重新读文档

## 1. 核心洞察

官方文档（如 Microsoft Learn）已经编码了：

- API 模式与用法指导
- 服务配置流程
- 平台最佳实践与约束
- 故障排查决策树
- 安全与合规要求

## 2. 三步骤方法论

1. **提取** — 从文档提取高价值、任务导向的能力
2. **分类** — 按目的分类（限制 / 故障排查 / 配置 / 架构 / 安全…）
3. **揭示** — 仅当与用户意图相关时按需加载

## 3. 预编译 vs RAG

| RAG 检索 | 预编译技能 |
|----------|-----------|
| 每次检索+摘要原始文本 | 知识预编译成动作/选择/护栏 |
| 需解释才能用 | agent 直接用 |
| 上下文成本高 | 按需加载 |
| 结果不稳定 | 确定性、可审 |

## 4. 每个技能的内容

- 按主题组织的精选文档链接
- 直接访问权威文档
- 最佳实践与架构模式
- 故障排查指南与常见坑

## 5. 自查清单

- [ ] 提取任务导向能力（非全文搬运）
- [ ] 按目的分类（限制/排查/配置/架构）
- [ ] 按用户意图按需揭示
- [ ] 预编译成动作/选择/护栏
- [ ] 带权威文档引用
- [ ] 团队可复用

## 边界

- 预编译技能需随文档演进维护——定期重编译。
- 与 RAG 互补：文档变化快时 RAG 兜底。
