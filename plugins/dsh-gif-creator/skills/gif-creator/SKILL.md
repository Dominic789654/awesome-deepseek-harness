# GIF Creator — GIF 创建

为 Slack 等场景创建或获取 GIF：搜索现成的、或生成自定义的。

## 何时用

- 用户要 GIF / 动图 / 表情包
- Slack 回复要配动图
- 自定义文字/帧动画 GIF

## 1. 搜索现成 GIF

- 用 GIF API（如 Giphy）搜索关键词
- 选择要点：与语境匹配、尺寸适中、可商用（注意授权）
- 返回 URL/文件，确认符合用户意图

## 2. 生成自定义 GIF

- 文字 GIF：文本 + 样式（字体/颜色/动画效果）→ 逐帧渲染
- 帧动画：多帧合成（每帧延时、循环设置）
- 简单图形动画：渐变/移动元素可脚本生成

## 3. 优化

- 尺寸：控制像素与帧数（Slack 有文件限制）
- 循环：无限循环 vs 有限次（按用途）
- 文件大小：压缩（帧数/颜色数/尺寸权衡画质）

## 4. 分享准备

- 确认目标平台要求（Slack 文件大小/格式）
- 给用户可直接粘贴/上传的产物（文件路径或 URL）

## 5. 自查清单

- [ ] 搜索场景：关键词准确、授权确认
- [ ] 自定义场景：文字/帧动画清晰
- [ ] 尺寸与文件大小适配目标平台
- [ ] 循环设置按用途
- [ ] 画质与体积平衡
- [ ] 产物可直接使用

## 边界

- GIF API 需要 key 与配额；本地生成免 key 但能力有限。
- 版权：搜索场景确认来源授权；生成场景全原创无风险。
