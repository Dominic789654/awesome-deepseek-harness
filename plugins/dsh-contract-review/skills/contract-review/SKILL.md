# Contract Review — 合同风险识别器

逐条审查合同文本，识别风险条款，输出分级风险报告与修改建议。
本技能提供的是风险提示与审查框架，不构成法律意见；重大事项建议咨询执业律师。

## 审查流程

1. **读全文**：先完整读取合同（文件或粘贴文本），识别合同类型
   （买卖/服务/租赁/劳动/合作/保密/股权等），不同合同重点不同。
2. **逐条核查**：按下方风险清单过一遍关键条款，定位原文。
3. **分级**：每条风险标注严重度 ——
   - 🔴 高：可能导致重大损失/违约/失去核心权利（如无限责任、单方解除权、
     无上限赔偿、知识产权归属不利）。
   - 🟠 中：存在明显不利或不公平条款（如付款条件苛刻、验收标准模糊）。
   - 🟡 低：表述不清、可能引发争议（如定义缺失、时间节点不明）。
4. **出报告**：风险编号 + 原文摘录 + 问题说明 + 修改建议 + 严重度。

## 关键条款核查清单

- **当事人与资质**：主体名称与营业执照一致；签字/盖章权限（授权代表）。
- **标的与范围**：标的物/服务范围明确；数量、质量标准、交付物清单。
- **价款与支付**：金额、币种、税率、支付节点与条件；违约金比例（过高可请求调整）；
  是否有预付款/保证金/账期风险。
- **交付与验收**：交付时间、地点、方式；验收标准与流程；验收期限（逾期视为验收？）。
- **违约责任**：违约情形定义；违约金/赔偿上限；责任是否对等（甲方乙方是否双标）。
- **知识产权**：成果归属（职务/委托/合作开发）；许可范围与期限；侵权担保与追偿。
- **保密与数据**：保密义务范围、期限；个人信息/数据合规（个保法）；数据出境。
- **解除与终止**：解除条件是否对等；提前解约通知期；终止后义务（归还资料、结算）。
- **不可抗力**：定义与后果；是否免除付款义务。
- **争议解决**：管辖法院/仲裁机构明确（避免"原告所在地""合同签订地"等模糊表述）；
  适用法律明确；诉讼/仲裁费用承担。
- **格式条款**：加重对方责任、排除对方主要权利的格式条款是否提示说明
  （民法典第 496-497 条相关风险）。
- **其他**：生效条件、附件完整性、条款独立性、通知送达条款、合同份数。

## 输出格式

```markdown
## 合同风险审查报告

**合同类型**：…（买卖/服务/…）
**总体评价**：…（如"整体风险中等，主要问题集中在付款与违约责任"）

### 风险清单
| # | 严重度 | 条款 | 原文摘录 | 问题 | 修改建议 |
|---|--------|------|----------|------|----------|
| 1 | 🔴 高 | 第 X 条 违约责任 | "…" | … | … |
| … |

### 必须修改项（高）
- …

### 建议谈判项（中）
- …

### 可接受项（低）
- …

> 免责声明：本报告为 AI 辅助风险提示，不构成法律意见。
```

## 注意事项

- 引用原文时保持准确，注明条款编号；不要改写合同原文。
- 不确定的法律问题（如特定法域）如实说明，建议咨询律师。
- 涉密合同：提醒用户注意保密义务后再处理内容。
