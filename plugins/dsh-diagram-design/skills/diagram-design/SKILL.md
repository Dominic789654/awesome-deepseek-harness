# Diagram Design — 编辑级图表设计

创建自包含 HTML 文件（内联 SVG+CSS）的视觉图表，遵循有主见的编辑式设计系统。

## 何时用

- 架构/IT 现状/流程图/时序/状态机/ER/时间线/泳道/象限/雷达/
  循环飞轮/嵌套/树/组织图/层叠/Venn/金字塔漏斗/树图/条形/折线/
  Gantt/散点/高层/流程/medallion/数据流/Sankey/鱼骨/Wardley/看板/
  用户旅程/部署/依赖图/UML 类图/story map/数据库 schema 图
- 重绘 .drawio/.mmd 源（指定尺寸/细节）
- 从网站提取品牌 token 上色

## 1. 哲学：最高质量的移动通常是删除

- 每个节点代表一个独立想法；总是结伴的节点合并
- 每条连线承载信息；布局已显然的关系删掉线
- **强调色是编辑手段不是旗帜**：每图 1-2 个焦点节点，
  用 5 个就抹掉了信号
- 图表不是加无可加时完成，而是**减无可减时完成**

## 2. 风格门（首次出图前）

- 新项目首图前确认风格指南已定制（默认纸色/墨色/强调色要换掉）
- 定制来源：网站 URL 提取 / 已装技能提取 / 设计系统目录 /
  手动贴 token / 加载保存的客户 profile
- 定制后跳过此门；可保存命名 profile 复用
- **别无声地把默认皮肤图发进品牌项目**

## 3. 语义模式与类型

- 语义模式描述行为（独立于布局）；类型引用描述布局
- 细节按需从 references 加载（渐进披露）
- 标注（callout）、无障碍动效、sketchy/手绘风格可选

## 4. 自查清单

- [ ] 风格指南已定制（非默认皮肤）
- [ ] 每节点独立想法、无冗余连线
- [ ] 强调色 1-2 焦点节点
- [ ] 类型与语义模式匹配需求
- [ ] 减无可减（完成标准）
- [ ] 输出自包含 HTML/SVG/PNG

## 边界

- 本技能是"编辑级图表"：拒绝 Mermaid 默认味，追求出版级设计。
- 类型 38 种：按需查阅对应类型引用，别一次性全读。
