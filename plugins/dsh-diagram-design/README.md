# dsh-diagram-design

DSH（DeepSeek Harness）技能插件：**编辑级图表设计**。

38 种图表类型为自包含 HTML+SVG（架构/流程/时序/状态机/ER/泳道/Wardley/Sankey/鱼骨/用户旅程等），编辑式设计系统（减无可减）、品牌风格门、语义模式、drawio/Mermaid 导入。受 [cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)（23k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-diagram-design
```

## 触发方式

描述中包含"架构图 / 流程图 / 图表 / 示意图 / 时序图 / 设计图表 / 反 Mermaid 味"等关键词时自动触发。

## 能力

- 38 种图表类型
- 编辑式设计系统（删除哲学）
- 品牌风格门与 token 提取
- 语义模式与渐进披露
