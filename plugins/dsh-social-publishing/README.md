# dsh-social-publishing

DSH（DeepSeek Harness）技能插件：**社媒内容发布**。

跨平台（X/LinkedIn/Instagram/抖音/小红书等）内容策划、平台原生文案改写、发布排期与限流规避、媒体素材按平台裁剪、发布后数据复盘。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-social-publishing
```

## 触发方式

描述中包含"发社媒 / 发帖 / 多平台发布 / 排期 / 内容战役 / 小红书文案 / 话题标签"等关键词时自动触发。

## 能力

- 平台差异速查（字符/标签/语气）
- 六步发布工作流与文案原则
- 排期校验与限流规避
- 程序化发布（聚合 API）与数据复盘
