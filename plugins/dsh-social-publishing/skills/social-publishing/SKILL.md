# Social Publishing — 社媒内容发布

一次策划、多平台发布：平台原生文案 + 合理排期 + 数据复盘。

## 何时用

- 多平台发布/排期帖子
- 策划多平台内容战役
- 上传附媒体素材
- 拉取帖子互动数据
- 程序化管理内容日历

## 1. 平台差异速查

| 平台 | 要点 |
|---|---|
| X | 短文本、线程（thread）连载、话题标签克制 |
| LinkedIn | 职场语气、公司页 + 个人页、长文友好 |
| Instagram | 视觉优先、话题标签多、Reels 视频 |
| 抖音/TikTok | 短视频描述、强钩子开头 |
| 小红书 | 种草语气、标题+标签、封面图关键 |
| Facebook | 页面帖、链接预览 |
| Discord/Telegram | 频道/群、嵌入卡片 |
| YouTube | 视频描述 + 元数据（标题/标签/章节） |
| Reddit | 子版块 + flair，社区语气 |
| WordPress | 博客 + SEO 元数据 |

## 2. 工作流

1. **定义战役**：平台、内容、排期、媒体附件
2. **平台原生改写**：每个平台单独写文案——字符限制、话题标签规范、语气
3. **媒体素材**：一次上传按平台裁剪（尺寸/比例）
4. **校验排期**：检查平台时段规则与限流，别踩发布频率墙
5. **发布/排期**：记录 post ID 与计划时间
6. **复盘**：发布 24-48h 后拉互动数据（曝光/点击/互动）

## 3. 文案原则

- **平台原生而非复制粘贴**：同一内容每平台改语气与格式
- 开头 1-2 行定生死（信息流只显示首屏）
- 一个帖子一个 CTA；标签按平台数量规范
- 视频平台文案配钩子 + 章节；图文平台配强封面

## 4. 程序化发布（可选）

- 聚合 API（如 SocialClaw）一个 key 管多平台，免逐平台 OAuth
- 上传一次媒体，按 ID 多帖复用
- 排期前再次确认，避免限流错误
- 数据：发布后拉 engagement 指标做下轮优化

## 5. 自查清单

- [ ] 每平台有原生改写（非复制粘贴）
- [ ] 字符限制与话题标签符合平台规范
- [ ] 媒体按平台尺寸裁剪
- [ ] 排期避开了平台限流时段
- [ ] 发布后有复盘数据收集
- [ ] 敏感内容/品牌语气符合规范

## 边界

- 各平台规则（字符/标签/频率）会变，发布前查最新规范。
- 程序化发布需对应服务账号与授权；企业账号注意合规与品牌审核。
