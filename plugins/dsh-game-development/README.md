# dsh-game-development

DSH（DeepSeek Harness）技能插件：**游戏开发模式**。

Godot 4 场景/信号/状态机与 GDScript 最佳实践、Unity ECS（DOTS/Jobs/Burst）面向数据设计、性能优化（对象池/批处理/Profile 先行）。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-game-development
```

## 触发方式

描述中包含"游戏开发 / Godot / GDScript / Unity / ECS / DOTS / 游戏系统 / 状态机"等关键词时自动触发。

## 能力

- Godot 节点/场景/信号架构与 GDScript 最佳实践
- 状态机与场景解耦设计
- Unity ECS 面向数据设计（ISystem/Burst/ECB）
- 性能优化自查清单
