# Investment Research — 个人投研方法论

不替你做决定——把行情、研报、估值、财务、公告、资金面、资讯配齐，
用你自己的 AI 驱动研究。方向与结论由你自己配置的模型/agent 给出。

## 何时用

- 个股投研（A 股为主，美股/港股参考）
- 每日复盘（大盘/短线情绪/板块资金）
- 对一只股票做多空辩论分析
- 审计一段已有分析的推理漏洞

## 1. 五维分析框架

让 AI 分析个股时按五维组织结论——框架只规定"怎么读数据"，不规定买卖：

1. **估值** — 前向 PE / PEG / 估值历史分位
2. **资金面** — 融资融券 / 主力资金流 / 龙虎榜 / 股东户数
3. **财报质量** — 三表 / ROE / 毛利率 / 负债率 / 现金流
4. **行业景气** — 板块归属 / 产业链环节 / 概念热度
5. **事件催化与风险** — 公告 / 解禁 / 新闻 / 互动易问答

## 2. 多空辩论（终点是分歧，不是结论）

```
① 事实底稿   按固定清单拉 13 项客观数据（不经 LLM）
              ↓  多空双方吵的是同一份数据，谁也不能靠编数字赢
② 多方研究员  基于底稿立论：核心论点 + 支撑证据 + 逻辑成立的前提
③ 空方研究员  基于底稿质疑：核心质疑 + 风险证据 + 逻辑成立的前提
   （可选）    交叉反驳：逐条回应对方，承认的明说，能反驳的给数据
④ 中立主持    双方共识 / 真正的分歧点（数据不足 vs 解读不同）/
              验证清单 / 数据缺口
```

刻意约束：

- **底稿先行**：数据确定、可复现，缺项如实写进底稿并要求"不得臆测"
- **每条论点必须标注所依据的具体数据**，无数据支撑要自己标注
- **中立主持不裁决谁对**、不给评级——产出是"你接下来该去看什么"
- 成本意识：一轮约 3 次模型调用；两轮（交叉反驳）5 次约翻倍；
  数据已在底稿里，中档模型足够

## 3. 反思审计

对一段已写好的分析做推理审计，揪出"听起来合理但没有依据"的部分——
如"获得机构广泛认可"（用三家推断整体）、"频繁上调预期"（未量化）。
开销小：1 次模型调用，输入就是选中文本（超长自动截断）。

## 4. 每日复盘要素

- 大盘指数 + 隔夜全球市场（道指/标普/纳指/恒指）
- 短线情绪：连板梯队 / 封板率 / 炸板率 / 晋级率
- 全市场成交额 TOP20、板块资金趋势、资金轮动
- 资讯雷达：12 赛道公开 RSS 源，AI 提炼"今日要点"

## 5. 合规与边界

- 只做客观数据整理与公开榜单呈现：不荐股、不预测涨跌、
  不给买卖时机、不承诺收益、不做主观评分
- 持仓/关注/研报/API key 只存本地
- 估值历史分位只标位置、不划买卖线

## 6. 自查清单

- [ ] 五维框架组织（估值/资金面/财报/景气/催化风险）
- [ ] 多空辩论：事实底稿先行 + 论点标注数据来源
- [ ] 中立主持归纳分歧与验证清单（不裁决）
- [ ] 反思审计跑过（无数据支撑的表述已标出）
- [ ] 合规：不荐股、不预测、不承诺收益

## 边界

- 仅供学习研究，不构成投资建议；股市有风险，独立决策。
- 数据来自公开源，需自行核实。
