# dsh-javascript-typescript

DSH（DeepSeek Harness）技能插件：**JavaScript/TypeScript 开发模式**。

现代 JS（ES6+ 最佳实践/async/函数式）、TS 高级类型（泛型/条件类型/映射类型/工具类型）、Node 后端与类型安全工程（API/表单校验）。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-javascript-typescript
```

## 触发方式

描述中包含"JavaScript / TypeScript / 泛型 / 条件类型 / 重构遗留 JS / Node 后端 / 类型安全"等关键词时自动触发。

## 能力

- 现代 JS 十五式最佳实践与常见坑
- TS 高级类型体系（泛型/映射/模板字面量/工具类型）
- 类型安全 API 客户端与表单校验
- Node 后端分层与流式处理
