# Canvas Design — 视觉设计

创建设计哲学（美学运动），然后在画布上**视觉化表达**。
产出 .md（哲学）、.pdf/.png（视觉作品）。

## 何时用

- 创建海报、艺术作品、设计
- 静态视觉（非 UI/非代码生成）
- 需要原创视觉设计

## 1. 两步流程

1. **设计哲学创作**（.md）
2. **在画布上表达**（.pdf 或 .png）

## 2. 设计哲学

创作一个**视觉哲学**（不是布局/模板），通过以下诠释：
- 形式、空间、色彩、构图
- 图像、图形、形状、图案
- 极简文字作视觉点缀

**关键理解**：用户输入是基础不约束创造自由；
产出是"设计哲学/美学运动"；下一步视觉化表达——
**90% 视觉设计、10% 必要文字**。

## 3. 表达纪律

- 哲学先行：先定形式/色彩/构图的"运动"方向，再动手
- 90/10 原则：视觉主导，文字只是点缀
- **原创性**：创作原创视觉设计，不复制现有艺术家作品
  （避免版权问题）
- 构图原则：留白/焦点/视觉动线服务于哲学

## 4. 自查清单

- [ ] 设计哲学已命名并阐述（形式/空间/色彩/构图）
- [ ] 90% 视觉 + 10% 文字
- [ ] 构图与色彩服务于哲学
- [ ] 输出 .md 哲学 + .pdf/.png 作品
- [ ] 原创（不复制他人作品）
- [ ] 视觉结果按哲学审校

## 边界

- 与算法艺术（代码生成）互补：本技能是静态视觉设计。
- 美学迭代：作品不达标回去改哲学/构图，别硬凑。
