# dsh-canvas-design

DSH（DeepSeek Harness）技能插件：**视觉设计**。

两步流程：创建设计哲学（美学运动：形式/空间/色彩/构图）→ 在画布上表达为海报/艺术作品（90% 视觉 + 10% 文字），原创不复制。受 [Anthropic 官方 skills](https://github.com/anthropics/skills) 的 canvas-design（Apache-2.0）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-canvas-design
```

## 触发方式

描述中包含"海报 / 视觉设计 / 艺术品 / 静态视觉 / 设计哲学 / 排版构图"等关键词时自动触发。

## 能力

- 设计哲学创作
- 90/10 视觉表达原则
- 构图与色彩服务哲学
- 原创性纪律
