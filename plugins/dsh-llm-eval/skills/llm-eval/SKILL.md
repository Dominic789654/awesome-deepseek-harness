# LLM Eval — LLM 评估

系统化评估 LLM 应用：定义指标 → 建测试集 → 跑评估 → 回归守护。

## 何时用

- 评估模型/提示词/应用改动前后的效果
- 检测幻觉与低质量输出
- 建回归测试集
- 对比不同模型/提示词/参数

## 1. 定义评估维度

| 维度 | 问什么 | 典型指标 |
|---|---|---|
| 忠实度 | 回答有依据吗？ | 忠实度分（是否基于给定上下文） |
| 相关性 | 回答答到点上了吗？ | 相关性分 |
| 正确性 | 事实/答案对吗？ | 与参考答案匹配率 |
| 完整性 | 覆盖所有要点了吗？ | 要点命中率 |
| 格式/安全 | 结构对吗？有毒有害吗？ | 格式合规、毒性检测 |

## 2. 建测试集

- **多样性**：覆盖常见场景、边界、失败模式（每类 ≥ 5-10 条）。
- **Ground truth**：预写参考答案/要点（人写或高可信来源）。
- **困难样本**：含易幻觉、易混淆、需要多步推理的用例。
- **持续扩充**：线上真实失败案例沉淀进测试集。

## 3. 跑评估

- **人工/LLM 评判**：打分（1-5）或二分类（pass/fail + 理由）。
- **规则检查**：答案是否包含来源、是否含禁止内容、格式是否合规。
- **指标聚合**：平均分、通过率、失败模式分布。
- **对比**：改动前后同测试集对比（A/B）。

## 4. 回归守护

- 关键 prompt/应用改动 → 跑测试集，比较通过率。
- 通过率下降 > 阈值（如 5%）→ 阻断发布。
- 记录每次评估结果（可追踪趋势）。

## 评估报告模板

```markdown
## LLM 评估报告

- **评估对象**：<应用/提示词版本>
- **测试集**：<N 条，分布说明>

| 维度 | 均分/通过率 | 主要失败模式 |
|---|---|---|
| 忠实度 | … | 3 条无依据回答 |
| 相关性 | … | … |

- **对比上次**：+/-…
- **结论**：通过 / 需改进（<具体问题>）
- **失败案例**：…（原文 + 期望 + 实际）
```

## 幻觉专项检测

- **无依据断言**：回答内容是否都在给定上下文里？不在的标出。
- **来源核对**：引用的来源是否真实存在且支持该说法。
- **矛盾检测**：回答内部或与已知事实矛盾。

## 边界

- 评估集与指标是"代理"，不等于真实用户满意度；定期用人反馈校准。
- LLM 评判本身可能偏差：关键决策用多评判员/人工复核。
