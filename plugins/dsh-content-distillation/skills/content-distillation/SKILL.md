# Content Distillation — 把内容蒸馏成可调用 skills

看了很多书、收藏了很多视频、听了很多播客，但用不起来——知识停留在
"看过/听过/收藏过"层面。本技能把这些高价值内容蒸馏成**可独立调用、
可组合、可压力测试**的 AI skill 工具包，而不是一篇摘要。

## 何时用

- 读完/看完/听完后想要一套能调用的方法论
- 书、有字幕/转写的视频、播客、访谈、演讲、课程、长文、资料集
- 判断标准：内容里存在可抽取、可验证、可迁移的方法论单元

**不用**：纯娱乐内容、无方法论的流水账、已有成熟 skill 覆盖的主题。

## 1. RIA-TV++ 七阶段流水线

1. **Adler 分析（整体理解）**：借鉴《如何阅读一本书》——对整份内容做
   结构、解释、批判、应用四步拆解，产出 `BOOK_OVERVIEW.md`
2. **并行提取**：同时派 5 个专项提取器（框架、原则、案例、反例、术语）
3. **三重验证筛选**：每个候选必须通过三项——
   - 原内容中至少 2 处独立佐证（跨域）
   - 能回答内容里未明说的新问题（预测力）
   - 不是常识（独特性）
   通过率通常只有 25-50%——严格筛选，不照单全收
4. **RIA++ 构造**：R（原文引用）/ I（用自己的话重写）/
   A1（书中案例）/ A2（未来触发场景）/ E（可执行步骤）/ B（边界与盲点）
5. **Zettelkasten 链接**：找出 skill 间依赖/对比/组合关系，生成 `INDEX.md` + 引用图
6. **压力测试**：每个 skill 设计含诱饵题的测试用例（含跨 skill 混淆测试），
   未通过的回炉重做
7. **交付**：生成面向读者的 `DIGEST.md` 精华长文；把通过测试的 skill
   安装进 agent 的 skills 目录，真正可被调用

## 2. RIA-TV++ 名字拆解

- **RIA**：赵周《这样读书就够了》便签拆书法（Reading / Interpretation / Appropriation）
- **TV**：Triple Verification 三重验证
- **++**：面向 agent 执行的扩展——E（可执行步骤）+ B（边界）

## 3. 输出产物

多 skill 仓库，而非单文件摘要：

- `BOOK_OVERVIEW.md` — 全局理解
- `INDEX.md` — 技能地图（依赖/对比/组合关系）
- `DIGEST.md` — 面向读者的精华长文
- `GLOSSARY.md` — 术语词典
- 若干 `*/SKILL.md` — 独立模块（触发条件 + 适用边界 + 使用方式）
- `test-prompts.json` — 验证触发场景的测试用例

## 4. 内容 vs 人的蒸馏

- **蒸馏人**（nuwa-skill）：思维方式、表达 DNA——"像 TA 一样说话"
- **蒸馏内容**（本技能）：方法论、框架、原则——"能帮人解决实际问题"
- 互补关系：模仿表达方式 vs 拆出系统性输出的方法论

## 5. 自查清单

- [ ] 内容存在可抽取/可验证/可迁移的方法论
- [ ] 5 提取器并行跑过（框架/原则/案例/反例/术语）
- [ ] 三重验证全过（跨域佐证/预测力/独特性）
- [ ] RIA++ 六维结构（含可执行步骤和边界）
- [ ] INDEX.md 引用图就位
- [ ] 诱饵题压力测试通过

## 边界

- 蒸馏不等于压缩：产出是结构化复用，不是更长说明文。
- 未通过验证的内容淘汰，不强行保留。
