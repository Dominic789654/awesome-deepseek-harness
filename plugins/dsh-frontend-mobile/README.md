# dsh-frontend-mobile

DSH（DeepSeek Harness）技能插件：**前端与移动开发**。

React Native/Expo 架构（导航/原生模块/离线优先/性能纪律）+ Next.js App Router（Server Components/流式渲染/并行路由/Server Actions/渲染模式选型）。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-frontend-mobile
```

## 触发方式

描述中包含"React Native / Expo / Next.js / App Router / Server Components / SSR / ISR / 移动 App"等关键词时自动触发。

## 能力

- Expo 项目结构与导航分组
- RN 性能纪律（FlashList/Reanimated/真机测试）
- Next.js 渲染模式选型与文件约定
- Server Actions、并行路由与数据获取
