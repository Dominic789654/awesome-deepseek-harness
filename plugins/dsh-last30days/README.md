# dsh-last30days

DSH（DeepSeek Harness）技能插件：**跨平台近 30 天研究**。

Reddit/X/YouTube/TikTok/HN/Polymarket/GitHub/arXiv 等并行搜索，按真实参与度（赞/币/真金白银）评分而非编辑推荐，AI 裁判综合成一份简报——开会前查人、招人信号、发现爆发前主题（discovery mode）、工具对比、理解世界动态。受 [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill)（26k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-last30days
```

## 触发方式

描述中包含"最近 30 天动态 / 查人 / 舆情 / 热点发现 / 招人信号 / 工具对比 / 真实参与度"等关键词时自动触发。

## 能力

- 16+ 平台并行搜索
- 按真实参与度评分（非编辑推荐）
- AI 裁判综合简报
- discovery mode（爆发前主题）
- --hiring-signals 招人信号
- --as-of 历史回看
