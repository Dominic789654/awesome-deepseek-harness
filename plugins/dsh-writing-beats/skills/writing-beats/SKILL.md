# Writing Beats — 节拍式写作

把素材组装成**节拍旅程**（选择你自己的冒险）：这是开采——素材堆已定，
承诺一条路径，挖素材填每节拍。

## 循环

1. **确立先决条件**：开始前与用户定下受众进门已**奠基**的概念；
   其他一切必须由某节拍奠基，后续节拍才能用
2. 写 2-3 个候选**起始节拍**（素材里不同的入口点），每个只能依赖
   已奠基概念，并注明各奠基什么新概念。展示给用户再写文件；
   用户选一个。预览这个选择解锁的节拍（让用户看到一点前路）
3. 选定后**只写那个节拍**到文章文件（一句到几段，视节拍自然形态），
   停在那里
4. **从磁盘重读**文章文件，然后提供 2-3 个候选**下一节拍**：
   从当前位置可转向的不同方向；每个必须从当前奠基集可达，注明各奠基什么
5. 循环 3-5 直到文章自然结束

## 什么是节拍

节拍 = 旅程中的一步移动，做一件事：设景、落地一个点、发问、
插一句题外话、扭转角度。然后停，把读者留在下一节拍可转向之处。

节拍按需定大小：
- 一句（"然后三周什么都没发生。"）
- 短段（移动需要铺垫）
- 多段（自包含小场景/论证/示例）

"节拍"需要五段 + 三个小标题 → 不是节拍，是两个节拍粘一起。拆。

## 奠基

- **先决条件**：首节拍前已奠基，受众自带
- **引入**：节拍确立，之后每个节拍都奠基

每节拍两个职责：**要求**已奠基的概念 + **奠基**新概念。
维护已奠基清单，每节拍落地更新。

这塑造了冒险结构：候选节拍可达 ⇔ 它要求的概念都已奠基；
选奠基 X 的节拍解锁所有等 X 的节拍。给候选时全部从当前奠基集
可达，并说明各奠基什么——用户看到哪些路径被打开。

**杠杆**：先决条件 vs 文内奠基。诱惑节拍要求无人奠基的概念 →
修复：前面加奠基节拍，或把概念提升为先决条件。

## 自查清单

- [ ] 先决条件与用户商定
- [ ] 候选起始/下一节拍各 2-3 个、只依赖已奠基概念
- [ ] 每节拍做一件事即停
- [ ] 边写边从磁盘重读
- [ ] 已奠基清单随节拍更新
- [ ] 无未奠基依赖（或已修复）

## 边界

- 节拍式适合路径分叉的叙述/教程；线性论证用塑形（shape）。
- 是开采模式：素材未探索完先探索。
