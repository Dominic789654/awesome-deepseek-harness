# Opinion Analysis — 多 Agent 舆情分析

"微舆"：从 0 实现的多智能体舆情分析系统——破除信息茧房、
还原舆情原貌、预测未来走向、辅助决策。用户只需像聊天一样
提出分析需求。

## 何时用

- 品牌声誉/热点事件/公众舆论深度分析
- 需要覆盖国内外多平台的大众真实声音
- 舆情走向预测与决策支持

## 1. 四类 Agent + 主持人

| Agent | 职责 |
|-------|------|
| **Query** | 国内外新闻/网页精准搜索 |
| **Media** | 多模态内容分析（短视频/图片/结构化卡片） |
| **Insight** | 私有数据库深度挖掘 |
| **Report** | 智能报告生成（内置模板多轮生成） |
| **主持人** | Agent"论坛"引导辩论 |

## 2. Agent"论坛"协作机制（核心）

- 不同 Agent 拥有**独特工具集与思维模式**
- 辩论主持人模型引导：**链式思维碰撞与辩论**
- 避免单一模型思维局限与交流同质化
- 催生更高质量的集体智能与决策支持

## 3. 完整分析流程

```
① 用户提问
② 并行启动：Query + Media + Insight 三 Agent 同时工作
③ 初步分析：各 Agent 用专属工具概览搜索
④ 策略制定：基于初步结果制定分块研究策略
⑤ 循环阶段：论坛协作 + 深度研究（每轮：深度研究 → 论坛
   主持人引导 → 交流融合调整方向）
⑥ 结果整合：Report Agent 收集所有分析结果与论坛内容
⑦ IR 中间表示：动态选模板样式，多轮生成元数据
⑧ 报告生成：分块质量检测，渲染交互式 HTML 报告
```

## 4. 能力要点

- **全域监控**：AI 爬虫集群 7x24 覆盖微博/小红书/抖音/快手等 10+ 社媒，
  下钻至海量用户评论
- **复合分析引擎**：5 类 Agent + 微调模型 + 统计模型多模型协同
- **多模态**：深度解析短视频内容、提取搜索卡片（天气/日历/股票）
- **公私域融合**：安全接口接入内部业务数据库（外部趋势 + 内部洞察）
- **轻量可扩展**：纯 Python 模块化，改 API 参数与 prompt 即可
  变成金融/市场等其他领域分析系统
