# SAST Security — SAST 工具配置

静态应用安全测试工具配置：自动发现代码漏洞，多语言、多工具纵深防御。

## 何时用

- 在 CI/CD 配置 SAST 扫描
- 为代码库创建自定义安全规则
- 配置质量门与合规策略
- 优化扫描性能、减少误报
- 多 SAST 工具集成（纵深防御）

## 1. Semgrep

- **自定义规则**：模式匹配（pattern matching）写规则
- 语言特定规则：Python/JavaScript/Go/Java 等
- CI/CD 集成：GitHub Actions/GitLab CI/Jenkins
- **误报调优**与规则优化
- 组织策略强制

## 2. SonarQube

- 项目配置与质量门（Quality Gates）
- 语言覆盖与规则集管理
- 增量扫描与历史趋势
- 合规策略映射

## 3. CodeQL

- 查询（query）编写：数据流/污点分析（跨函数调用链）
- 自定义安全查询
- 大规模代码库分析

## 4. 配置纪律

- **先跑默认规则集**，再按代码库定制（别一上来全自定义）
- 误报调优：加白名单/细化模式，但记录理由（防静默放宽）
- 质量门：严重级漏洞阻断合并；低危可放行但进待办
- 扫描性能：增量扫描、按变更文件扫描
- 与 DAST/依赖扫描互补（SAST 管"自己写的代码"）

## 5. 自查清单

- [ ] 默认规则集先跑通，再定制
- [ ] 自定义规则有测试（防误报/漏报）
- [ ] CI 集成 + 质量门生效
- [ ] 误报处理有记录
- [ ] 扫描性能优化（增量）
- [ ] 与 DAST/依赖扫描互补

## 边界

- SAST 有局限（动态/运行时问题看 DAST；依赖漏洞看依赖扫描）。
- 工具特性差异大，按所选工具文档配置。
