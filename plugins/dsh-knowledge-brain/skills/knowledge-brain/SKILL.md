# Knowledge Brain — 知识大脑层

搜索给你原始页面，GBrain 给你答案。大脑层 = 合成 + 图谱遍历 +
差距分析，一体。

## 何时用

- agent 需要记住"不是代码的东西"（人/公司/会议/想法）
- 会议前快速准备（对方在做什么/上次聊什么/还欠什么）
- 公司级制度记忆（团队共享、按权限隔离）

## 1. 三大独特能力

- **合成层**：跨人/公司/交易/想法的实际答案（带引用的流畅散文），
  不是"10 个相关片段"
- **自连线知识图谱**：每次页面写入零 LLM 调用提取实体引用并创建
  类型边（attended/works_at/invested_in/founded/advises）——
  "谁在 Acme 工作？""Bob 这季度投了什么？"向量搜索够不着的问题
- **差距分析**：明确标注"大脑还不知道什么"——避免被惊喜

## 2. 梦境周期（24/7 消化）

- 夜间自动：消化（ingest）→ 丰富（enrich）→ 巩固（consolidate）
- 摄取会议/邮件/推文/语音/原始想法（睡眠时）
- 修复自己的引用、巩固记忆
- "醒来比我睡前更聪明"

## 3. 公司大脑（团队隔离）

- 每人一片，按登录作用域隔离
- 查询只见自己权限内的数据（模糊测试零泄漏）
- 团队共享的制度记忆（YC RFS "company-brain" 形态）

## 4. 关键设计

- **你拥有大脑**：每条记忆都是私有仓库里的 markdown 文件
  （可读、可克隆、删除即消失）
- **本地运行**：你的硬件、你的 DB、你的 keys
- **零 API key 起步**：关键词 + agent 自写记忆；可选升级语义
  搜索与自动事实提取
- 跨会话往返：告诉它一件事 → 重启 → 问回来 → 答案来自大脑
  而非上下文

## 5. 自查清单

- [ ] 写入提取实体边（零 LLM 调用）
- [ ] 合成答案带引用 + 来源页
- [ ] 差距分析标注未知
- [ ] 梦境周期开启（夜间消化/巩固）
- [ ] 多用户按登录隔离
- [ ] 记忆可导出/可删除（你拥有）

## 边界

- 大脑答案是合成——重要事实回源核实。
- 公司作用域是团队记忆，非合规档案；敏感数据按策略隔离。
