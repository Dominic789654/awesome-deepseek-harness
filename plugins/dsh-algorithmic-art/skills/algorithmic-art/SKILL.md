# Algorithmic Art — 算法艺术生成

算法哲学是计算美学运动，通过代码表达。产出：`.md`（哲学）、
`.html`（交互视图）、`.js`（生成算法）。

## 两步流程

1. **算法哲学创作**（.md）
2. **用 p5.js 表达**（.html + .js）

## 1. 算法哲学创作

创作一个**算法哲学**（非静态图/模板），将通过以下方式被诠释：
- 计算过程、涌现行为、数学之美
- 种子随机、噪声场、有机系统
- 粒子、流、场、力
- 参数变化与受控混沌

**关键理解**：用户输入是基础不约束创造自由；
产出是"算法哲学/生成美学运动"；下一步用代码表达它——
90% 算法生成、10% 必要参数。

**生成方法**：
- **命名运动**（1-2 词）："Organic Turbulence" / "Quantum Harmonics"
- **阐述哲学**（4-6 段，简洁完整）：计算过程与数学关系？
  噪声函数与随机模式？粒子行为与场动力学？时间演化与系统状态？
  参数变化与涌现复杂度？
- **关键指南**：避免冗余（每个算法方面提一次）；
  **反复强调匠心**（"精心设计的算法""大师级实现"等框架）；
  留创作空间（算法方向具体、给下个实现者解释空间）

美在过程，不在最后一帧。

## 2. 用代码表达

- p5.js 草图：种子随机（可复现）、噪声场/流场、粒子系统、
  多层噪声、时间演化
- 交互视图：参数探索（滑块调整让观众参与）
- 原创性：**创作原创算法艺术，不复制现有艺术家作品**
  （避免版权问题）

## 3. 自查清单

- [ ] 运动已命名、哲学 4-6 段阐述
- [ ] 哲学含涌现/计算/种子变化重点
- [ ] 无冗余重复、匠心强调到位
- [ ] p5.js 表达 90% 算法 + 参数可探索
- [ ] 种子随机可复现
- [ ] 原创（不复制他人作品）

## 边界

- 生成艺术是迭代过程：先哲学后代码，代码不达标回去改哲学。
- 交互与美学平衡：别让参数面板喧宾夺主。
