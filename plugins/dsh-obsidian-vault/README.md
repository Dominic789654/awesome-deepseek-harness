# dsh-obsidian-vault

DSH（DeepSeek Harness）技能插件：**Obsidian 知识库操作**。

Obsidian 风味 Markdown（wikilinks/embeds/callouts/properties）、Bases 数据库视图（views/filters/formulas/summaries）、JSON Canvas 画布（nodes/edges/groups）、Obsidian CLI（插件与主题开发）、Defuddle 网页转净 Markdown（去杂乱省 token）。受 [kepano/obsidian-skills](https://github.com/kepano/obsidian-skills)（36k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-obsidian-vault
```

## 触发方式

描述中包含"Obsidian / vault / 双链笔记 / callout / JSON Canvas / Bases 视图 / Defuddle"等关键词时自动触发。

## 能力

- 风味 Markdown（wikilink/embed/callout/properties）
- Bases 视图/过滤/公式/汇总
- JSON Canvas 节点/边/组
- Obsidian CLI 插件开发
- Defuddle 网页净提取
