# dsh-hr-legal-compliance

DSH（DeepSeek Harness）技能插件：**HR 与法律合规**。

雇佣合同/录用通知/员工手册/NDA 模板与关键条款、员工 vs 承包商界定、GDPR 数据处理（同意管理/数据主体权利/隐私设计/DSR 流程）。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-hr-legal-compliance
```

## 触发方式

描述中包含"雇佣合同 / 录用通知 / HR 政策 / NDA / GDPR / 数据主体权利 / 同意管理 / 隐私合规"等关键词时自动触发。

## 能力

- 雇佣文档类型与关键法律考量
- GDPR 数据分级与处理合法性依据
- 同意管理与数据主体请求流程
- 隐私设计工程实现要点
