# Internal Comms — 内部沟通写作

用公司习惯的格式写各类内部沟通：状态、计划、问题、公告、FAQ。

## 何时用

- 3P 更新（Progress 进度/Plans 计划/Problems 问题）
- 公司通讯（newsletter）
- FAQ 回答（常见问题）
- 状态报告 / 领导层更新 / 项目更新 / 事件报告

## 流程

1. **识别沟通类型**：从请求判断属于哪类
2. **加载对应指南**：按类型取格式模板——
   3P 更新 / 公司通讯 / FAQ 回答 / 通用沟通
3. **按指南执行**：格式、语气、内容收集都按该文件的指示

不匹配任何现有指南 → 问澄清或要更多上下文（期望的格式）。

## 各类要点

- **3P 更新**：进度（完成什么）/计划（接下来做什么）/问题（卡在哪，
  需要什么支持）——简短、具体、可行动
- **公司通讯**：开头结论 → 分部展开；语气统一；给读者"与我何干"
- **FAQ 回答**：直接回答在前，背景在后；诚实标注不确定
- **状态/领导层更新**：对齐目标/指标/风险；决策点清晰
- **项目更新**：里程碑 vs 计划、阻塞与变更、下一步
- **事件报告**：时间线、影响、根因、修复与预防（无责语气）

## 通用纪律

- 受众导向：给谁看决定信息密度与语气
- 结论先行（busy 读者先看结论）
- 具体 > 空泛：数字、日期、负责人
- 请求行动时给明确选项与截止时间

## 自查清单

- [ ] 沟通类型已识别并匹配指南
- [ ] 结论先行、受众导向
- [ ] 3P/里程碑/指标具体可行动
- [ ] 事件报告无责 + 时间线 + 根因 + 预防
- [ ] 行动请求有选项与截止
- [ ] 无匹配时已澄清格式

## 边界

- 各公司有自家格式偏好：有现成模板就严格遵循。
- 内部沟通影响信任：事实准确 > 包装漂亮。
