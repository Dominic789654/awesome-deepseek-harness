# Content Marketing — 内容营销

AI 驱动的内容营销全链路：创作 → SEO → 分发 → 复盘，以转化为导向。

## 何时用

- 制定内容营销策略
- AI 内容创作与批量生产
- SEO 内容优化（关键词/SERP/结构化数据）
- 社媒内容策略与自动化
- 邮件序列与自动化
- 多渠道分发与内容再利用
- 内容效果分析与转化优化

## 1. 内容创作

- **选题**：AI 辅助头脑风暴 + 趋势分析；主题集群（topical cluster）
  围绕支柱内容组织
- **多格式**：一文多用（博客→社媒→邮件→视频脚本→信息图）
- 符合"帮助性内容"指南：为读者价值写，不为搜索引擎凑
- 批量工作流：模板化 + 人工审校（AI 初稿不是终稿）

## 2. SEO 优化

- 关键词研究 + 语义 SEO（实体/同义词覆盖）
- **SERP 差距分析**：对手已排名的词你缺哪些
- 结构化数据（schema）做富摘要；Featured Snippet/位置零优化
- 技术 SEO：Core Web Vitals、内部链接、站点结构

## 3. 社媒内容策略

- 平台差异化（LinkedIn/X/IG/TikTok 各写各的）
- 自动化排期（Buffer/Hootsuite 类）；话题标签研究
- 视觉内容（Canva/Midjourney 类）；UGC 与达人合作

## 4. 邮件与分发

- 行为触发序列 + 动态内容个性化；主题行 A/B 测试
- 可送达性：列表卫生、退订管理
- 多渠道分发：内容再利用 + 付费推广 + 客座文章 + 播客/视频

## 5. 数据复盘

- GA4 跟踪内容表现（流量/停留/转化）
- 漏斗转化率优化（CRO）：标题/CTA/格式 A/B
- ROI 与归因建模：内容 → 线索 → 收入的路径

## 6. 自查清单

- [ ] 主题集群与支柱内容结构清晰
- [ ] 关键词 + SERP 差距分析完成
- [ ] 内容符合帮助性指南、一文多格式
- [ ] 平台差异化 + 排期自动化
- [ ] 邮件序列有触发 + 主题行测试
- [ ] GA4/CRO 复盘有数据支撑

## 边界

- 营销工具/平台规则变化快，按当前最佳实践与合规（广告法/平台政策）。
- 内容是长线：先一致性产出 + 复盘迭代，别追求单篇爆款。
