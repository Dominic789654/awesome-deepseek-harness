# dsh-content-marketing

DSH（DeepSeek Harness）技能插件：**内容营销**。

AI 内容创作（主题集群/一文多格式）、SEO 优化（关键词/SERP 差距/结构化数据/技术 SEO）、社媒内容策略、邮件自动化、多渠道分发与 GA4 数据复盘。受 [wshobson/agents](https://github.com/wshobson/agents)（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-content-marketing
```

## 触发方式

描述中包含"内容营销 / SEO 内容 / 内容策略 / 主题集群 / 邮件序列 / 内容分发 / 内容复盘"等关键词时自动触发。

## 能力

- 主题集群与多格式创作工作流
- SEO 优化（SERP 差距/富摘要/技术 SEO）
- 平台差异化与排期自动化
- GA4/CRO 数据复盘
