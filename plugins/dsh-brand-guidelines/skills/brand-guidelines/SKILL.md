# Brand Guidelines — 品牌风格应用

把品牌色板与字体应用到任何受益于品牌外观的制品。

## 何时用

- 品牌颜色/风格指南适用时
- 视觉格式化/品牌化输出
- 公司设计标准
- 后处理/统一视觉

## 1. 色板结构（以示例品牌为参考）

**主色**：
- 深色：`#141413`（主文本/深背景）
- 浅色：`#faf9f5`（浅背景/深底上的文本）
- 中灰：`#b0aea5`（次要元素）
- 浅灰：`#e8e6dc`（细微背景）

**强调色**：
- 橙：`#d97757`（主强调）
- 蓝：`#6a9bcc`（次强调）
- 绿：`#788c5d`（第三强调）

## 2. 字体配对

- **标题**：Poppins（回退 Arial）
- **正文**：Lora（回退 Georgia）
- 环境预装字体效果最好；自动回退保证全系统可读

## 3. 应用纪律

- 标题（24pt+）用标题字体；正文用正文字体
- **智能配色**：按背景选文字色（深底浅字/浅底深字）
- 非文本形状（图形/装饰）用强调色，橙→蓝→绿轮换
- 保持视觉层级与可读性（品牌 ≠ 牺牲可读性）
- 精确色值（RGB/HEX）保证跨系统色彩保真

## 4. 自查清单

- [ ] 色板按主/辅/强调结构应用
- [ ] 标题/正文字体配对 + 回退
- [ ] 文字色按背景智能选择
- [ ] 形状用强调色轮换
- [ ] 视觉层级保留、可读性优先
- [ ] 色值精确（HEX/RGB）

## 边界

- 示例色板来自参考品牌；实际项目用自家品牌指南的色值。
- 品牌指南是起点：与设计系统/无障碍（对比度）要求结合。
