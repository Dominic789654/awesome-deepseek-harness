# dsh-brand-guidelines

DSH（DeepSeek Harness）技能插件：**品牌风格应用**。

品牌色板（主/辅/强调）与字体配对（标题/正文 + 回退）应用到任意视觉制品、按背景智能配色、非文本形状用强调色轮换、视觉层级与可读性纪律。受 [Anthropic 官方 skills](https://github.com/anthropics/skills) 的 brand-guidelines（Apache-2.0）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-brand-guidelines
```

## 触发方式

描述中包含"品牌视觉 / 品牌色 / 统一风格 / 品牌化 / 设计标准 / 视觉格式化"等关键词时自动触发。

## 能力

- 色板结构（主/辅/强调）
- 字体配对与回退
- 按背景智能配色
- 强调色轮换与可读性优先
