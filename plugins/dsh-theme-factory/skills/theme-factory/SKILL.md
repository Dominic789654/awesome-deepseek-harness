# Theme Factory — 主题工厂

用精心挑选的配色与字体配对主题装饰任意制品（幻灯片/文档/报告/HTML 落地页）。

## 何时用

- 给演示文稿/文档/报告/落地页统一专业风格
- 需要一致视觉身份、适合不同受众与场合

## 1. 主题库（10 个预设）

示例主题（每个含：连贯色板 HEX + 标题/正文字体配对 + 独特视觉身份）：
Ocean Depths（专业冷静海洋）/ Sunset Boulevard（暖亮日落）/
Forest Canopy（自然大地色）/ Modern Minimalist（当代灰度）/
Golden Hour（暖秋）/ Arctic Frost（冷冽冬季）/ Desert Rose（柔雅尘粉）/
Tech Innovation（大胆科技）/ Botanical Garden（清新有机）/
Midnight Galaxy（戏剧宇宙深调）

## 2. 应用流程

1. **展示主题看板**：让用户看到所有主题的视觉预览（不改动看板本身）
2. **问选择**：要应用哪个主题
3. **等确认**：得到明确确认
4. **应用**：把选定主题的颜色与字体一致地应用到制品
   （读对应主题规格 → 全制品一致应用 → 保证对比度与可读性）

## 3. 现场生成新主题

预设都不合适 → 按需现场生成：
- 明确色板（HEX）与字体配对（标题/正文）
- 定义视觉身份（面向场合与受众）
- 与预设主题同样完整规范（可复用）

## 4. 应用纪律

- 一致性优先：选定后全制品统一，不中途混用
- 对比度与可读性：品牌/主题再美，读不清就是失败
- 颜色精确（HEX/RGB 保真）

## 5. 自查清单

- [ ] 主题看板展示、用户明确选择并确认
- [ ] 选定主题的颜色与字体全制品一致应用
- [ ] 对比度与可读性达标
- [ ] 现场生成的主题有完整规范（色板/配对/身份）
- [ ] 未混用多个主题
- [ ] 色值精确

## 边界

- 主题是装饰层：内容结构优先，主题随后。
- 与品牌指南互补：有品牌色板就用品牌主题，否则用通用主题。
