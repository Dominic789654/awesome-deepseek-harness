# Sales Automation — 销售自动化与客服

以转化与关系为导向的销售外联 + 客服响应：价值先行、短而可扫、单一 CTA。

## 何时用

- 冷邮件序列与个性化外联
- 跟进战役与节奏（cadence）
- 提案/报价模板
- 案例与社证
- 销售话术与异议处理
- 客服响应与工单

## 1. 冷邮件序列

**产出**：3-5 触点序列、A/B 主题行、个性化变量、跟进计划表、
异议处理脚本、监控指标。

**原则**：
- **价值先行**：先讲价值不讲功能（lead with value, not features）
- **个性化**：基于研究（公司/角色/最近动态），不群发模板
- **短而可扫**：邮件保持简短，一眼能读完
- **单一 CTA**：一封邮件一个行动点
- **共情**：理解对方问题，像人一样说话

**跟进节奏**：首封 → 2-3 天跟进（补价值）→ 最后接触（礼貌退出）；
每封跟进提供新信息，别只是"ping"。

## 2. 提案与社证

- 提案模板：问题 → 方案 → 价值量化 → 报价 → 下一步
- 案例研究：客户背景 → 挑战 → 方案 → 结果（数字说话）
- 异议处理：预写常见异议脚本（价格/时机/信任/竞品）

## 3. 客服响应

- **共情先行**：先承认问题与情绪，再讲解决方案
- **分级处理**：能自助的给步骤；复杂的上报/转人工
- **闭环**：解决后确认满意度，记录案例供复用
- 语气一致、避免机械模板感（个性化开头）

## 4. 度量

- 跟踪：打开率/回复率/转化率（邮件）；首次响应时间/解决率（客服）
- A/B 测试主题行与 CTA，按数据迭代

## 5. 自查清单

- [ ] 序列 3-5 触点、每封有新增价值
- [ ] 个性化基于研究、非模板群发
- [ ] 一封一 CTA、短而可扫
- [ ] 异议脚本覆盖常见反对
- [ ] 客服共情先行 + 闭环确认
- [ ] 打开/回复/转化有跟踪

## 边界

- 外联合规（反垃圾邮件法/平台规则）按辖区执行；B2B 冷邮控制在合理频率。
- 销售是关系活：自动化是放大不是替代，个性化决定成败。
