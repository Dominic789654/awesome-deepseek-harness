# dsh-brand-landingpage

DSH（DeepSeek Harness）技能插件：**品牌优先落地页设计**。

品牌身份访谈（产品/感觉/视觉）→ 设计系统（色彩/字体/形状 token）→ 落地页结构与文案 → 生成-反馈迭代循环 → 可部署 HTML（响应式+性能）。受 [wshobson/agents](https://github.com/wshobson/agents) 的 brand-landingpage（38k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-brand-landingpage
```

## 触发方式

描述中包含"做落地页 / 设计首页 / 营销页 / 品牌视觉 / 网站视觉方向 / landing page"等关键词时自动触发。

## 能力

- 三段式品牌访谈框架
- 设计系统 token 翻译
- 生成-反馈迭代循环
- 落地页结构清单与交付纪律
