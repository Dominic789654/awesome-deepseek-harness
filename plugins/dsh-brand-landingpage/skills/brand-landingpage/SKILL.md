# Brand Landing Page — 品牌优先落地页设计

用户有产品但没想过品牌与视觉：用品牌访谈把答案翻译成设计决策，产出可部署落地页。

**范围**：单目的落地页与产品营销页。不做多页应用/仪表盘/文档站。

## Phase 1: 品牌访谈（价值所在，别跳过）

三段式访谈：
- **A 产品**：做什么、给谁、核心价值、一句话卖点
- **B 品牌感觉**：想传达的气质（专业/活泼/高端/极客）、竞品风格、喜欢/讨厌的网站
- **C 视觉**：色彩倾向、字体气质、形状语言（圆润/尖锐/几何）

用户想直接生成时温和坚持——没有访谈产出的是通用模板。

## Phase 2: 翻译成设计系统

- **色彩**：主色 + 辅助色 + 强调色，明确语义（CTA/背景/文本）
- **字体**：标题/正文配对，层级清晰
- **形状语言**：圆角/图标风格/间距节奏统一
- 记录为设计 token（变量），后续迭代一致

## Phase 3: 生成与迭代循环

`生成 → 展示 → 结构化反馈 → 修改/变体 → 重复`

- 一次聚焦一个问题（先结构再视觉再文案）
- 反馈用结构化问题引导：层级是否清楚？CTA 是否突出？情绪是否符合品牌？
- 每轮改动小步，可对比前后

## Phase 4: 交付

- 部署就绪 HTML/CSS（无外部依赖或注明）
- 响应式：桌面/平板/手机三档验证
- 性能：图片压缩、字体子集化、最小化 JS
- 交付说明：如何部署、如何改内容

## 落地页结构清单

- 首屏：价值主张 + 主 CTA（一句话说清做什么）
- 信任区：数据/客户 logo/证言
- 产品/功能区：3 个以内卖点，图配文
- 行动号召区：重复 CTA
- 页脚：联系 + 次要链接

## 自查清单

- [ ] 品牌访谈完成（产品/感觉/视觉三段）
- [ ] 设计系统有色彩/字体/形状 token
- [ ] 首屏一句话价值主张 + 主 CTA
- [ ] 迭代循环一次一个焦点
- [ ] 三档响应式 + 性能已处理
- [ ] 交付含部署说明

## 边界

- 这是营销页设计流程，不做 App UI/仪表盘/组件库。
- 生成工具（Stitch 等）可用则用；无工具时手写 HTML/CSS 同流程。
