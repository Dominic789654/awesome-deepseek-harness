# dsh-workflow-loop

DSH（DeepSeek Harness）技能插件：**可委托工作流设计**。

用"循环"视角找出生活中可委托的重复模式，通过盘问产出 workflow 规格：触发（事件/计划）、检查点推送靠右、决策就绪简报，直到实现者无需提问即可构建。受 [mattpocock/skills](https://github.com/mattpocock/skills) 的 loop-me（223k★ MIT）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-workflow-loop
```

## 触发方式

描述中包含"可委托工作流 / 循环自动化 / 流程规格 / 日常重复 / 委托 / workflow 设计"等关键词时自动触发。

## 能力

- 循环视角发现可委托模式
- 触发/检查点/简报词汇
- 推送靠右（人类一次且晚）
- 规格完成标准（无需提问可构建）
