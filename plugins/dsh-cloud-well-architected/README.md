# dsh-cloud-well-architected

DSH（DeepSeek Harness）技能插件：**云 Well-Architected 六支柱评审**。

可靠性（按用户经验目标定义、SLO/错误预算、跨区域冗余、水平扩展、golden signals 可观测性、优雅降级、恢复测试、无指责复盘）、成本优化、运维卓越、性能优化、安全、可持续性——设计原则 + 建议驱动云工作负载评估与改进。受 [google/skills](https://github.com/google/skills)（18.5k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-cloud-well-architected
```

## 触发方式

描述中包含"Well-Architected / 云架构评审 / 可靠性设计 / SLO 设定 / 灾备 / 六支柱"等关键词时自动触发。

## 能力

- 六支柱评审框架
- 可靠性原则（用户体验目标/SLO/冗余/扩展）
- golden signals 可观测性
- 优雅降级与恢复测试
- 无指责复盘
- 评估工作流（检查→差距→建议）
