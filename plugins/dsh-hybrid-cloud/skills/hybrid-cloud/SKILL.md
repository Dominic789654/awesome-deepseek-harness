# Hybrid Cloud — 混合云网络

本地与云端安全互联：VPN 起步、专线提速、双活扩展、合规渐进迁移。

## 何时用

- 本地数据中心连云
- 数据中心扩展到云
- 混合云双活（active-active）
- 满足合规要求（数据驻留等）
- 渐进式迁移上云

## 1. 连接方式对比

**Site-to-Site VPN（IPSec）**：
- 走互联网，每隧道最高约 1.25 Gbps
- 中带宽下性价比高；延迟高、依赖互联网质量

**专线（Direct Connect / ExpressRoute / Interconnect / FastConnect）**：
- 专用物理连接；1 Gbps–100 Gbps
- 低延迟、带宽稳定；更贵、需提前开通

选型：起步/中带宽 → VPN；生产/低延迟/大带宽 → 专线。
关键生产链路通常 **VPN 兜底 + 专线主用** 双通道。

## 2. 核心设计

- 路由与 BGP：专线/VPN 上跑 BGP 动态路由，故障自动切换
- 网段规划：本地与云 VPC 网段不重叠，避免路由冲突
- 安全：加密通道 + 安全组/防火墙规则收敛；敏感流量走专线（不经过公网）
- 高可用：双隧道/双专线（不同物理路径），跨可用区冗余

## 3. 双活与灾备

- 数据库跨地复制 + 应用双活部署
- DNS/全局负载均衡就近接入
- 定期故障切换演练（VPN↔专线、主↔备区域）

## 4. 合规与渐进迁移

- 数据驻留：哪些数据留本地、哪些上云，按合规要求画线
- 迁移节奏：先非核心工作负载 → 验证网络质量 → 再迁移核心
- 回退计划：保留本地环境直到云端稳定

## 5. 自查清单

- [ ] 连接选型合理（VPN/专线/双通道）
- [ ] 网段不重叠、BGP 动态路由就位
- [ ] 双隧道/双专线冗余 + 自动切换
- [ ] 安全组与防火墙收敛、敏感流量走专线
- [ ] 双活/灾备有复制 + 切换演练
- [ ] 数据驻留合规已画线、迁移有回退

## 边界

- 各云商专线产品与计费不同（Direct Connect/ExpressRoute/Interconnect/FastConnect），按云商细则。
- 混合云网络排障复杂：先分层定位（物理/隧道/路由/安全组）。
