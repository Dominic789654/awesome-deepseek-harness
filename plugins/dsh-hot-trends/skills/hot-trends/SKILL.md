# Hot Trends — 中国热点数据采集

使用 `hot_trends` 工具获取实时榜单数据，免 API Key。

## 可用来源

| source | 榜单 | 说明 |
|---|---|---|
| `weibo` | 微博热搜 | 含讨论量 |
| `baidu` | 百度热搜 | 含热度分 |
| `bilibili` | B站全站排行榜 | 视频播放热度 |
| `zhihu` | 知乎热榜 | 含热度说明 |
| `appstore` | App Store 免费榜（中国区） | 应用名称+开发者 |
| `qqmusic` | QQ音乐飙升榜 | 歌曲+歌手 |

## 使用方式

1. 判断用户想要的榜单类型，选择对应 `source`。
2. 调用 `hot_trends`，`limit` 默认 20（可调 1-50）。
3. 把结果整理成用户友好的回答：可分组、可补充背景、可对比多来源。

## 多来源组合示例

- "今天全网都在聊什么" → 调 `weibo` + `baidu` + `bilibili`，合并去重后呈现。
- "最近有什么好听的歌" → `qqmusic`。
- "有什么新 App 值得关注" → `appstore`。

## 失败处理

- 某来源失败时换其他来源重试，不要反复重试同一来源。
- 接口为公开非官方端点，可能随时变化；如实告知用户数据时效与来源。
