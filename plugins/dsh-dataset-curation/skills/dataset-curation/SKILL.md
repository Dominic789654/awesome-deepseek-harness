# Dataset Curation — 数据集整理

微调效果的上限由数据决定——**数据质量 > 模型技巧**。整理出干净、多样、
高质量的数据集。

## 何时用

- 准备 LLM 微调/训练数据
- 清洗与去重数据集
- 质量筛选与多样性控制
- 构建训练/验证/测试拆分
- 建立标注规范

## 1. 清洗

- **去重**：精确/近似去重（重复样本扭曲分布）。
- **去噪**：错别字、格式错乱、截断样本、乱码。
- **过滤有害内容**：PII、有毒、不当内容（合规红线）。
- **去无关**：主题不符/质量太差的样本（低分样本拉低微调效果）。

## 2. 质量筛选

- 用规则 + 模型打分筛选高质量样本（参考 llm-eval 的评估方法）。
- 关注：正确性、清晰度、格式符合目标风格。
- 保留失败/边界样本做验证（测试模型短板）。

## 3. 多样性与分布

- **覆盖分布**：样本覆盖任务类型的全谱（简单/中等/困难）。
- **平衡类别**：避免某类过多某类过少（均衡或按意图加权）。
- **真实数据优先**：从真实使用/日志采集，比人工编造更贴近线上。
- **标注一致性**：多人标注时用规范 + 抽查一致性（inter-annotator）。

## 4. 拆分与格式

- **拆分**：训练/验证/测试（如 80/10/10），**测试集绝不参与训练与调参**。
- **格式**：按训练框架要求（chat template/instruction format 统一）。
- **版本管理**：数据集入库、可追溯（来源/版本/变更）。

## 5. 标注规范

- 写清楚标注指南（正例/反例、边界情况、禁忌）。
- 标注模板统一（字段、格式、长度）。
- 抽查标注质量，反馈修正。

## 交付清单

- [ ] 数据去重/去噪完成（数量与处理记录）
- [ ] 有害/PII 过滤完成
- [ ] 质量筛选（高分样本占比、保留比例）
- [ ] 类别分布统计（均衡性检查）
- [ ] 训练/验证/测试拆分（不泄漏）
- [ ] 格式统一 + 版本管理
- [ ] 样本统计报告（总条数/分布/样例）

## 边界

- 具体框架（SFT/DPO/RLHF）的数据格式不同，按目标框架调整。
- 数据规模与质量平衡：小而精 > 大而杂（微调尤其如此）。
