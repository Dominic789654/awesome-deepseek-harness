# Quant Backtest — 量化回测与风险指标

构建生产级的稳健回测系统，规避常见偏差，得到可靠的策略表现估计。

## 何时用

- 开发交易策略回测
- 搭建回测基础设施
- 验证策略表现
- 规避回测偏差
- 实现 walk-forward 分析
- 比较策略备选

## 1. 回测系统设计

- **数据**：用干净、复权（adjusted）的历史数据；明确数据源与期间。
- **信号→仓位**：规则明确（入场/出场/仓位大小/止损），无模糊逻辑。
- **成本**：**必须计入**交易成本（佣金、滑点、冲击成本）——忽略成本的回测
  高估收益，实盘必亏。
- **口径一致**：回测逻辑与实盘逻辑一致（同一信号源、同一执行假设）。

## 2. 三大偏差（必须规避）

- **前视偏差（Look-ahead）**：使用了未来信息（如用当日收盘价计算当日信号）。
  规避：信号只用截止 t-1 的数据；滚动计算指标。
- **幸存者偏差（Survivorship）**：只回测今天还存在的标的（退市的没算）。
  规避：用**当时点**的成分/标的集合，纳入已退市标的。
- **过拟合**：参数在样本内调优过度。规避：样本外测试 + walk-forward。

## 3. Walk-Forward 分析

- 把历史切成滚动窗口：训练窗（定参数）→ 测试窗（验证）。
- 逐步前移，多次验证；最终表现 = 各测试窗的拼接。
- 比单次"训练/测试"分割更接近实盘。

## 4. 风险指标计算

| 指标 | 含义 | 公式要点 |
|---|---|---|
| 收益率 | 策略收益 | 年化收益 |
| 夏普比率 | 风险调整后收益 | (收益 - 无风险) / 波动 |
| 最大回撤 | 峰值到谷底最大跌幅 | max(peak - trough) / peak |
| 胜率 | 盈利交易占比 | 盈利次数 / 总次数 |
| 盈亏比 | 平均盈利/平均亏损 | avg win / avg loss |
| VaR | 给定置信度下的最大损失 | 历史/参数法分位数 |

**解读纪律**：夏普 > 1 可接受，> 2 优秀；最大回撤要能承受（结合心理与资金）；
高收益 + 超高回撤 = 高风险。

## 5. 回测报告模板

```markdown
## 回测报告：<策略>

- **标的/期间**：… / …
- **数据与成本假设**：…

### 表现
- 年化收益：…  夏普：…  最大回撤：…  胜率：…  盈亏比：…

### 偏差检查
- [ ] 无前视偏差（信号只用 t-1 数据）
- [ ] 无幸存者偏差（含退市标的）
- [ ] 已计入交易成本
- [ ] walk-forward 验证通过

### 结论与风险
- …
```

## 边界

- 回测表现 ≠ 未来表现；实盘前用小资金纸面验证。
- 本技能提供方法论，不构成投资建议。
