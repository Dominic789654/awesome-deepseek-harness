# Plugin Eval — 插件/技能质量评估

衡量 skill/插件质量的权威方法论：三层叠加、十维评分、可解释可改进。

## 何时用

- 理解插件质量如何被测量
- 解读某个维度的低分
- 决定如何改进技能的触发准确率/编排适配度
- 校准市场评分阈值
- 解释质量徽章

## 1. 三层评估

**Layer 1 静态分析**（<2 秒、无 LLM、确定性）：
- frontmatter 质量（名称/描述长度/触发词质量）
- 编排接线（输出/输入文档、代码块、orchestrator 反模式）
- 渐进披露（行数 200-600 甜蜜区、references/assets 加分）
- 结构完整（标题密度/代码块/示例/排障章节）
- token 效率（MUST/NEVER 密度、重复行比）
- 生态一致性（交叉引用其他 skill、"related/see also"）

反模式惩罚（乘法）：每多一个反模式扣 5%，下限 50%。

**Layer 2 LLM 评委**（30-90 秒、非确定性、多评委取均值 + Cohen's kappa）：
- 触发准确率（F1，10 个心理测试提示）
- 编排适配度（worker 纯度 0-1）
- 输出质量（模拟 3 个真实任务评估指令质量）
- 范围校准（相对类别的深度与广度）

**Layer 3 蒙特卡洛模拟**（5-20 分钟、N=50 次调用）：
- 激活率（触发比例）
- 输出一致性（质量分变异系数 CV）
- 失败率（Clopper-Pearson 置信区间）
- token 效率（中位数/IQR/异常值）

```
mc_score = 0.40×激活率 + 0.30×(1−min(1,CV)) + 0.20×(1−失败率) + 0.10×效率归一化
```

## 2. 复合评分与徽章

- 各维度按权重融合三层分数
- 徽章阈值：按复合分划分等级（解释给外部伙伴时用同一套口径）
- Elo 排名：跨插件相对排名

## 3. 改进指南

- 触发准确率低 → 优化 description 触发词（前 20 词含核心触发）
- 编排适配度低 → 确保 worker 纯净（单一职责，不越权编排）
- 输出质量低 → 强化指令质量与示例（3 个真实任务演练）
- 结构分低 → 补示例/排障章节，行数进甜蜜区
- token 效率低 → 压缩重复，用 MUST/NEVER 高密度表达

## 4. 自查清单

- [ ] frontmatter 触发词质量高（前 20 词命中）
- [ ] worker 纯净、无 orchestrator 反模式
- [ ] 行数 200-600、含示例与排障章节
- [ ] 无重复冗余、token 高效
- [ ] 有交叉引用（生态一致）
- [ ] 三个真实任务演练输出质量

## 边界

- 评估是改进的输入：先解读维度低分，再针对性修改，别盲目加内容。
- 具体实现（PluginEval 等）工具各异，方法论本身通用。
