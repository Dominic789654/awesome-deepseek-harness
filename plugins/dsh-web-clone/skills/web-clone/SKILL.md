# Web Clone — 网页复刻

把参考网页（截图/URL/描述）拆解成完整设计规格，再生成还原度高的项目。
不是"照着感觉写"，而是**先提取细节，再逐项还原**。

## 流程

### 1. 获取参考

用户提供：截图 / URL / 或一段描述。URL 优先抓取真实页面（HTML/CSS/JS）
提取信息；截图则逐区域分析。

### 2. 提取设计规格（关键！）

逐项提取并记录：

- **字体**：标题/正文的字族、字重、字号、行高；中文字体回退栈。
- **颜色**：主色/背景/文字/强调色（十六进制），明暗模式（若有）。
- **间距与布局**：网格、栅格列数、断点、页面边距、区块间距。
- **动画与交互**：hover 效果、滚动动画、过渡时长与缓动、光标交互。
- **组件结构**：导航/卡片/轮播/表单/页脚等组件及其层级。
- **资源 URL**：图片、视频、图标库、字体文件的实际 URL（能拿到就引用，
  拿不到用等价占位并标注）。

输出一份"复刻规格"（markdown），**先给用户确认规格再写代码**——
规格对了，还原度才有保障。

### 3. 选择技术栈

- 单文件 HTML 就够 → 用纯 HTML/CSS/JS（零依赖，最易复刻）。
- 复杂交互/组件库风格 → React + Vite + Tailwind（或用户指定栈）。
- 与用户确认栈的选择（除非用户已指定）。

### 4. 生成实现

- 按规格逐区块实现：先结构（HTML/组件树），再样式（CSS token 统一），
  再交互（动画/事件）。
- 保持还原度优先级：布局 > 配色 > 字体 > 动效（动效最后，不要为动效牺牲还原）。
- 响应式：至少 320/768/1280 三档检查。

### 5. 自查与交付

- 对照规格逐项自查（[参照 frontend-design 自查清单]）。
- 交付：项目文件 + 运行方式 + "与原稿的差异说明"（哪些是故意简化/无法还原）。

## 规格模板

```markdown
## 复刻规格：<名称>

- **技术栈**：…
- **字体**：标题=… 正文=…（回退：…）
- **配色**：主=#… 背景=#… 文字=#… 强调=#…
- **布局**：栅格=… 断点=… 边距=…
- **组件**：…（导航/卡片/表单等清单）
- **动画**：…
- **资源**：…
```

## 边界

- 版权：仅复刻用于学习/个人用途；商用需确认原稿授权（提示用户）。
- 复杂原稿（视频背景、3D、专有库）如实说明可还原度，不硬编假效果。
