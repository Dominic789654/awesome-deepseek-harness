# dsh-swarm-prediction

DSH（DeepSeek Harness）技能插件：**群体智能预测引擎**。

从种子信息（突发新闻/政策草案/财务信号）构建高保真平行数字世界：数千个有独立人格、长期记忆、行为逻辑的智能体自由互动与社会演化，上帝视角动态注入变量推演未来轨迹——在数字沙盘里预演未来，无数次模拟后赢得决策。受 [666ghj/MiroFish](https://github.com/666ghj/MiroFish)（71k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-swarm-prediction
```

## 触发方式

描述中包含"预测走向 / 平行世界模拟 / 群体智能 / 社会演化 / 推演结局 / what if 场景"等关键词时自动触发。

## 能力

- 五步工作流（建图→环境→模拟→报告→深度交互）
- 数千智能体独立人格/记忆/行为
- 集体涌现（swarm emergence）
- 上帝视角变量注入
- 零风险决策演练
