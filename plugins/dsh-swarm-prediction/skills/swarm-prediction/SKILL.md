# Swarm Prediction — 群体智能预测

把真实世界的种子信息构建成高保真平行数字世界：数千个有独立
人格、长期记忆、行为逻辑的智能体自由互动、社会演化。从上帝
视角注入变量，推演未来——**在数字沙盘里预演未来，无数次模拟
后赢得决策**。

## 何时用

- 预测舆情事件走向 / 政策影响 / 市场走势
- 推演虚构故事结局（如《红楼梦》佚稿）
- 决策者零风险演练（政策/公关试错）
- 任何"what if"场景

## 1. 输入与输出

**输入**：种子材料（数据分析报告/新闻/小说）+ 自然语言预测需求
**输出**：详细预测报告 + 可深度交互的高保真数字世界

## 2. 五步工作流

1. **Graph Building** — 种子提取 + 个体/集体记忆注入 + GraphRAG 构建
2. **Environment Setup** — 实体关系提取 + Persona 生成 + Agent 配置注入
3. **Simulation** — 双平台并行模拟 + 自动解析预测需求 + 动态时序记忆更新
4. **Report Generation** — ReportAgent 带丰富工具集，与模拟后环境深度交互
5. **Deep Interaction** — 与模拟世界中任意 agent 对话 + 与 ReportAgent 交互

## 3. 核心机制

- **智能体多样性**：独立人格、长期记忆、行为逻辑——不是同质化克隆
- **社会演化**：个体交互触发**集体涌现**（swarm emergence）
- **上帝视角变量注入**：动态改参数，观察未来轨迹变化
- **零风险演练**：宏观是决策者预演实验室，微观是个人创意沙盘

## 4. 自查清单

- [ ] 种子信息提取（真实世界锚点）
- [ ] 个体/集体记忆注入 + GraphRAG
- [ ] Persona 生成（独立人格/记忆/行为）
- [ ] 多轮社会演化模拟
- [ ] 上帝视角变量注入（推演分支）
- [ ] 报告 + 深度交互交付

## 边界

- 预测是推演不是保证——决策仍需现实交叉验证。
- 模拟轮次有成本（40 轮内控制消耗）。
