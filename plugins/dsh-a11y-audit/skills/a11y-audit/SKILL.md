# A11y Audit — WCAG 2.2 无障碍审计

审计网页内容的 WCAG 2.2 合规性，给出可执行的修复建议。

## 何时用

- 审计网站无障碍性
- 修复 WCAG 违规
- 实现无障碍组件
- 应对 ADA/Section 508 合规要求
- VPAT 合规评估

## 核心概念

### 合规等级

| 等级 | 含义 | 适用 |
|---|---|---|
| A | 最低无障碍 | 法律基线 |
| AA | 标准合规 | 多数法规要求 |
| AAA | 增强无障碍 | 特定需求 |

### POUR 原则

- **Perceivable 可感知**：用户能感知内容吗？
- **Operable 可操作**：用户能操作界面吗？
- **Understandable 可理解**：用户能理解内容吗？
- **Robust 健壮**：辅助技术能用吗？

## 审计流程

### 1. 自动化扫描（先跑）

- 检查语义 HTML：标题层级（单一 h1、不跳级）、landmark（header/nav/main/
  article/aside/footer）、列表/表格语义。
- 检查图片：所有 img 有 alt（装饰性图片 alt=""）。
- 检查表单：每个输入有 label；错误提示关联 aria-describedby。
- 检查对比度：正文 ≥ 4.5:1，大字 ≥ 3:1（WCAG AA）。
- 检查键盘可达：所有交互元素可 Tab 到达、可回车/空格触发；focus 可见。

### 2. 人工验证（自动化查不出）

- 只用键盘走一遍完整流程（Tab/Shift+Tab/Enter/Esc）。
- 屏幕阅读器抽查（NVDA/VoiceOver）关键流程。
- 检查动态内容：aria-live 区域、弹窗焦点管理（打开聚焦、关闭归还）。
- 检查视频/音频：字幕、转录、音频描述。

### 3. 违规分级与报告

按严重度输出：

```markdown
## 无障碍审计报告

**目标**：<URL/页面>
**等级目标**：AA（默认）

### 违规清单
| # | 严重度 | WCAG 准则 | 位置 | 问题 | 修复建议 |
|---|--------|-----------|------|------|----------|
| 1 | 高 | 1.1.1 非文本内容 | … | img 无 alt | 补描述性 alt |

### 高严重度（阻断）
- …

### 中严重度
- …

### 低严重度/建议
- …
```

严重度分级：
- **高**：阻断核心功能（键盘不可达、无替代文本、无 label）
- **中**：影响部分用户（对比度不足、焦点不明确）
- **低**：体验优化（AAA 级增强）

### 4. 修复与复验

- 逐个修复，每个修复后复验对应违规点。
- 常见修复：补 alt/label/aria、调对比度、加 focus 样式、修标题层级、
  键盘事件补 focus 管理。

## 边界

- 自动化审计不替代完整人工/专业审计；涉及法律合规（ADA/508）建议专业评估。
- 只报告与修复建议，不擅自改动用户代码（除非被要求）。
