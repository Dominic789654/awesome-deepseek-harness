# dsh-html-template-library

DSH（DeepSeek Harness）技能插件：**HTML 模板库方法论**。

34 个 HTML 幻灯片设计系统的库：agent 读 index.json 匹配用户 brief、克隆选定模板、适配内容——Soft Editorial/Neo-Grid Bold/Stencil & Tablet/Sakura Chroma/Vellum/Monochrome 等，每模板 3 张多布局截图 + 元数据 + 可复用设计系统。受 [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates)（4k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-html-template-library
```

## 触发方式

描述中包含"设计系统模板 / 选模板 / 克隆适配 / HTML 幻灯片风格库 / 视觉方向"等关键词时自动触发。

## 能力

- 34 个设计系统
- index.json 选型匹配
- 克隆 + 适配工作流
- 3 张多布局预览
- 可复用设计 token
