# CSS Art Styles — CSS 艺术风格配方

为落地页与 UI 提供可复用的视觉风格系统：每种风格 = 设计系统
（色彩/字体/圆角/工具类/动效），即取即用不重造。

## 何时用

- 落地页/UI 需要独特视觉风格（避免模板感）
- 快速套用成熟美学（液态玻璃/电影感等）
- 风格一致性（跨页面同一设计系统）

## 1. 风格配方结构

每种风格提供：
- **设计系统**：背景/前景色、字体配对（标题/正文 + 回退）、
  圆角覆盖（如全 pill）、间距节奏
- **工具类 CSS**：精确样式块（如 `.liquid-glass` 两档变体：
  微妙版用于导航/卡片，强化版用于主 CTA）
- **动效**：入场动画（framer-motion 类）与交互反馈
- **布局骨架**：Hero + 能力区等区块结构

## 2. 风格示例

- **液态玻璃（Glassmorphism）**：半透明 + 模糊 + 亮度混合
  的玻璃质感（subtle/strong 两档），深色背景上最出效果
- **电影感太空**：循环背景视频 + 交叉淡入 + 衬线标题字体
- **有机花朵/冰冻美学**：自然色彩与形态主题

## 3. 应用纪律

- 风格是设计系统不是贴纸：全局一致应用（圆角/字体/色彩 token）
- 技术栈按需：CDN 单文件（React+Tailwind）或轻量原生
- 动效克制：服务叙事，不喧宾夺主
- 可访问性：对比度与动效偏好（prefers-reduced-motion）

## 4. 自查清单

- [ ] 风格设计系统完整（色彩/字体/圆角/间距）
- [ ] 工具类 CSS 精确（变体分明）
- [ ] 全站一致应用（无风格漂移）
- [ ] 动效克制 + 尊重减少动效偏好
- [ ] 深色背景风格检查对比度
- [ ] 技术栈匹配（CDN/原生）

## 边界

- 风格配方是起点：按品牌/内容调色与调字体。
- 与品牌指南/主题工厂互补：本技能提供艺术风格，它们管统一应用。
