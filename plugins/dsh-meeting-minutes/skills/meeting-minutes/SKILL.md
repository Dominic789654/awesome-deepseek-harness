# Meeting Minutes — 会议纪要自动生成

把会议录音转写稿/文字稿整理成结构化、可执行的会议纪要。

## 输入

- 转写文本（粘贴或文件），或
- 录音/视频文件路径（需先转写；说明转写方式与准确率）。

## 生成流程

1. **通读**：完整读一遍材料，识别会议主题、议程结构与参会角色。
2. **提炼**：按板块整理 ——
   - 会议信息：主题、日期、主持人、参会人、时长。
   - 议程与讨论要点：每个议题的讨论内容与结论。
   - 决策：明确拍板的事项（谁、什么、何时生效）。
   - 行动项：任务 + 负责人 + 截止时间 + 依赖；区分已确认与待确认。
   - 风险与阻塞：讨论中暴露的问题、未决事项。
3. **校验**：行动项是否都有负责人与时间？决策是否可执行？有歧义处标注"待确认"。
4. **输出**：见下方模板；同时可提议把行动项写入任务列表/周报。

## 输出模板

```markdown
# 会议纪要：<主题>

- **时间**：YYYY-MM-DD HH:mm
- **参会人**：…
- **主持人**：…
- **目标**：…

## 讨论要点
1. **<议题一>**：…（结论：…）
2. …

## 决策
- [ ] <决策1（谁，何时生效）>
- …

## 行动项
| 任务 | 负责人 | 截止 | 状态 |
|---|---|---|---|
| … | … | … | 待办 |

## 风险与待确认
- …

## 下次会议
- 待办：…
```

## 注意事项

- 区分"说了什么"与"决定了什么"：不要把所有发言都写成决策。
- 行动项负责人写具体人名/角色，不写"相关同事"。
- 转写稿有噪声（口误、重复）时先清洗；听不清的关键处标注"[听不清]"。
- 涉及敏感信息（薪资、人事）时提醒用户脱敏后再分发。
