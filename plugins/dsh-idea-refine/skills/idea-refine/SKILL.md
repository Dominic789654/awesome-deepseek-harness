# Idea Refine — 想法打磨

把原始想法打磨成**值得做**的清晰概念：先发散（扩大选项），再收敛
（评估收窄），最后产出可执行的一页纸。

## 三步流程

### 1. 理解与发散（Divergent）

- **复述想法**：用你自己的话重述，确认理解一致。
- **提问锐化**：问澄清问题——目标用户？核心价值？成功标准？约束？
  与现有方案的区别？
- **生成变体**：提出 3-5 个变体/方向（包括"反向"和"更小版"），
  不评价好坏，先把选项铺开。

### 2. 评估与收敛（Converge）

- **聚类**：把变体按主题分组，找共同点与冲突点。
- **压测**：每个候选用"最坏情况"测试——如果没人用/没预算/被抄袭，
  还值得做吗？
- **暴露隐藏假设**：这个想法依赖什么假设才成立？哪些假设可能错？
  逐条列出。

### 3. 锐化与产出（Ship）

输出一页纸概念文档：

```markdown
## 概念：<名称>

- **一句话**：为谁，解决什么问题，凭什么。
- **目标用户**：…
- **核心价值**：…
- **范围（做/不做）**：…
- **关键假设**：…
- **成功标准**：…
- **下一步**：…（验证假设的最小动作）
```

## 触发词

"帮我想想" / "打磨这个想法" / "stress-test 我的计划" / "这个主意怎么样" /
"我有个模糊的想法"。

## 与其它技能配合

- 想法打磨后 → planning（拆解执行）或 spec-driven（写规格）。
- 需要追问细节时 → grill-me（苏格拉底追问）。
- 本技能偏"发散-收敛结构"，grill-me 偏"逐个击破决策树"——可叠加。

## 边界

- 对话式进行：一次聚焦一个想法，不一次打磨多个。
- 产出一页纸即可，不写长篇商业计划（除非用户要求）。
