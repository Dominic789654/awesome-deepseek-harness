# Social Simulation — 百万 agent 社交模拟

可扩展的开源社媒模拟器：LLM agent 逼真模仿 Twitter/Reddit 上
多达**一百万用户**的行为——研究信息传播、群体极化、羊群行为
等复杂社会现象。

## 何时用

- 研究信息扩散 / 群体极化 / 羊群行为
- 模拟社媒生态与用户互动
- 测试内容传播策略（发布前）
- 生成社交互动数据集

## 1. 核心特性

- **规模**：最多 100 万 agent，规模接近真实平台
- **动态环境**：实时适配社交网络与内容变化（Twitter/Reddit 风格）
- **23 种动作空间**：follow / comment / repost 等丰富互动
- **推荐系统**：基于兴趣 + 热度评分的内容发现模拟

## 2. 典型研究场景

| 场景 | 观察什么 |
|------|----------|
| 信息传播 | 一条内容如何扩散、谁在传播 |
| 群体极化 | 立场如何走向极端 |
| 羊群行为 | 从众如何形成 |
| 内容策略 | 发布前预测传播效果 |

## 3. 工作流

1. 定义模拟环境（平台风格/网络结构/初始用户画像）
2. 配置 agent 行为（动作空间/推荐算法）
3. 运行模拟（可扩展到百万规模）
4. 收集交互数据（轨迹/社交图）
5. 分析社会现象与模式

## 4. 自查清单

- [ ] 环境定义（平台/网络/画像）
- [ ] 动作空间配置（23 种）
- [ ] 推荐算法选定（兴趣/热度）
- [ ] 规模匹配研究问题
- [ ] 数据收集与分析计划
- [ ] 结果与现实对照验证

## 边界

- 模拟是近似，不是真实平台观测——结论需谨慎外推。
- 生成数据集用于研究；分发遵守模型与数据许可。
