# Webapp Testing — Web 应用测试（Playwright）

用 Playwright 与本地 Web 应用交互和测试：验证前端功能、调试 UI、
截屏、查看浏览器日志。

## 何时用

- 验证前端功能
- 调试 UI 行为
- 截取浏览器截图
- 查看浏览器日志

## 决策树

```
用户任务 → 是静态 HTML？
  ├─ 是 → 直接读 HTML 文件找选择器
  │        ├─ 成功 → 用选择器写 Playwright 脚本
  │        └─ 失败/不完整 → 按动态处理
  └─ 否（动态 Web 应用）→ 服务器已在跑？
       ├─ 否 → 用辅助脚本起服务器 + 写简化 Playwright 脚本
       └─ 是 → 侦察后行动：
            1. 导航并等 networkidle
            2. 截图或查 DOM
            3. 从渲染态识别选择器
            4. 用发现的选择器执行动作
```

## 纪律

- **用辅助脚本管理服务器生命周期**（支持多服务器）：
  先 `--help` 看用法，别先读源码（脚本可能很大污染上下文；
  它们是黑盒脚本，直接调用）
- 动态应用：**先侦察再行动**——渲染后再找选择器，
  别猜未渲染的 DOM
- 交互断言：点击/输入/导航后验证期望状态
- 查浏览器日志（console/network 错误）定位问题

## 自查清单

- [ ] 决策树走对（静态直读/动态起服务器）
- [ ] 动态应用先侦察（等 networkidle + 截图/DOM）
- [ ] 选择器从渲染态识别
- [ ] 辅助脚本先 --help、未污染上下文
- [ ] 交互后验证期望状态
- [ ] 浏览器日志已查看

## 边界

- 与 E2E 方法论互补：本技能是 Playwright 实操工作流，
  E2E 是测试策略（金字塔/flaky/CI）。
- 具体脚本用法以 `--help` 为准，别凭记忆调用。
