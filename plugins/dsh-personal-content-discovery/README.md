# dsh-personal-content-discovery

DSH（DeepSeek Harness）技能插件：**跨平台个性化内容发现**。

以用户为中心而非内容标签：行为分析推断 MBTI/认知风格/深层需求，构建五层灵魂画像（事件→偏好→觉察→洞察→灵魂），主动猜测陌生兴趣破信息茧房，跨平台兴趣融合（B站/小红书/抖音/YouTube/X/知乎/Reddit…），本地优先 + 朋友式推荐解释 + 反馈闭环学习。受 [whiteguo233/OpenBiliClaw](https://github.com/whiteguo233/OpenBiliClaw)（2.9k★）启发的中文原创精简版。

## 安装

```bash
dsh plugin add dsh-personal-content-discovery
```

## 触发方式

描述中包含"个性化推荐 / 内容发现 / 破信息茧房 / 用户画像 / 灵魂画像 / 跨平台兴趣"等关键词时自动触发。

## 能力

- 五层灵魂画像（事件→偏好→觉察→洞察→灵魂）
- MBTI 推断 + 认知风格 + 深层需求
- 主动探索机制（猜对升级、猜错安静退出）
- 跨平台兴趣融合
- 四态反馈闭环（confirm/reject/defer/chat）
- 本地优先 + 朋友式可解释推荐
