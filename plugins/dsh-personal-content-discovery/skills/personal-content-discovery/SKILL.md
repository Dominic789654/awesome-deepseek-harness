# Personal Content Discovery — 跨平台个性化内容发现

传统推荐是"中间商"：平台把内容与用户匹配，优化的是平台指标，
信息茧房越推越窄。本技能反过来——先深度理解"你这个人"，
再根据理解跨平台主动搜寻你会喜欢、甚至你自己都不知道会喜欢的内容。

## 何时用

- 搭建个性化内容推荐/发现系统
- 破信息茧房：主动探索陌生但可能感兴趣的领域
- 跨平台兴趣融合：把割裂在各平台的兴趣连成完整画像
- 需要"朋友式"可解释推荐（告诉用户为什么推荐）

## 1. 核心原则

- **从人出发，不从标签出发**：不是内容匹配标签，而是行为分析推断
  MBTI、认知风格、深层心理需求，理解的是"人"不是点击记录
- **主动探索而非被动匹配**：基于理解主动猜测可能感兴趣但从未接触的
  领域——猜对了升级为正式兴趣，猜错了安静退出（不惩罚）
- **本地优先**：画像/行为/推荐数据留本机（SQLite），LLM 用用户自己的 Key
- **可解释**：像朋友一样解释推荐理由，不是"猜你喜欢"

## 2. 五层灵魂画像

从事件逐层抽象到灵魂，每层是下层的总结：

1. **事件** — 原始行为信号：观看/点赞/收藏/搜索/时长
2. **偏好** — 从事件归纳的主题/风格/形式偏好
3. **觉察** — 偏好背后的认知模式与兴趣结构
4. **洞察** — 动机与心理需求（深层需求、价值取向）
5. **灵魂** — 综合人格素描：MBTI（四维+置信度）、认知风格、核心特质

画像持续演进：每次反馈/对话都回写画像，下一轮推荐即更新。

## 3. 跨平台融合与破茧

- **跨平台兴趣融合**：B站看的机械键盘 + 小红书种草的咖啡器具 +
  YouTube 长视频 + X 点赞资讯 = 一个完整的你；画像融合让推荐不割裂
- **破茧逻辑**：协同过滤永远不会推"没人走过的路径"，
  主动探索会——用心理学桥接逻辑（关注机械表→可能喜欢建筑美学）
- **探索四态反馈**：confirm / reject / defer / chat，画像自动更新

## 4. 反馈闭环

- 喜欢/不感兴趣/稍后看/收藏/聊一聊 → 全部进入记忆系统
- 对话调教：直接聊天告诉它想看什么
- 推荐带理由 → 用户反馈 → 画像更新 → 下一轮推荐更准

## 5. 隐私与边界

- 数据默认留本机；外部同步必须显式授权
- 不代登录、不爬你看不到的内容；复用浏览器已有登录会话
- 默认假设：本地优先、用户可控（换 LLM / 改画像 / 迁移数据）

## 6. 自查清单

- [ ] 从人出发（行为→画像），非标签匹配
- [ ] 五层画像结构（事件→偏好→觉察→洞察→灵魂）
- [ ] 主动探索机制 + 四态反馈
- [ ] 跨平台兴趣融合
- [ ] 朋友式推荐解释
- [ ] 本地优先 + 用户可控

## 边界

- 画像推断是概率性的，标注置信度，不替用户下结论。
- 内容源接入需尊重各平台条款与用户授权。
