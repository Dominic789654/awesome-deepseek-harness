# Career Ops — 求职指挥中心

把求职当作战役来管理：用结构化评分评估每个职位，集中火力投匹配度高的，
用数据跟踪进展，每次面试后复盘改进。

## 工作流总览

1. **评估（Evaluate）**：收到 JD 后先做 A-F 结构化评分，再决定投不投。
2. **优化（Optimize）**：针对目标 JD 定制简历与求职信。
3. **执行（Execute）**：投递、跟踪、面试准备、复盘，形成闭环。

---

## 1. 评估 JD（A-F 评分）

收到 JD 文本或链接时，按以下维度逐项评估，输出评分表：

| 维度 | 考察点 | 打分 1-5 |
|---|---|---|
| 匹配度 | 你的技能/经验与 JD 要求的重合度 | |
| 成长性 | 职位能带来的技能/职级/行业跳板 | |
| 薪酬 | 薪资范围与市场对比（若未披露标注未知） | |
| 公司质量 | 公司规模、融资/上市状态、口碑、行业前景 | |
| 风险 | 明显红旗（职责模糊、试用期过长、加班文化信号等） | |

总分换算：25-20 分 = **A**（强烈推荐投递）；19-15 = **B**；14-10 = **C**；
9-5 = **D**（除非别无选择否则不投）；<5 = **F**（不投，说明理由）。

**评估输出格式**：

```markdown
## 职位评估：<公司> - <岗位>

- **评分**：A/B/C/D/F（总分 X/25）
- **匹配亮点**：…
- **关键差距**：…
- **红旗**：…
- **建议**：投 / 观望 / 不投 — 理由…
```

**红旗检测清单**：JD 无具体职责、薪资范围缺失且岗位描述空洞、要求全能型
（"精通一切"）、描述中出现大量空洞形容词（"宇宙级""颠覆性"）、试用期
明显不合理、职责与岗位名称不符。发现红旗要在报告中明确标出。

## 2. 简历与求职信优化

针对目标 JD 定制简历：

1. **提取 JD 关键词**：技能、工具、领域、软素质要求。
2. **逐条映射**：你的每段经历挑出与 JD 关键词最相关的 1-2 个成就。
3. **量化改写**：把"负责 XX"改成"通过 XX 使 XX 提升 30% / 缩短 50% / 支撑 XX 规模"。
4. **ATS 检查**：确保关键词原文出现（ATS 按字面匹配）；不用图表/分栏/图片
   承载关键信息；日期格式统一；PDF 导出。
5. **求职信（选做）**：3-4 段——为什么是这个岗位、我做过什么直接相关的事、
   我能带来什么、期待面谈。不复制简历，讲一个具体故事。

**输出**：优化后的简历全文（或 diff 说明改了哪里、为什么）+ ATS 自查清单结果。

---

## 3. 求职管线与跟踪

- **管线文件**：建议在工作区维护 `pipeline.md`，记录每个职位：
  公司 / 岗位 / JD 链接 / 评分 / 投递日期 / 状态（待投→已投→笔试→面试→Offer→挂）。
- **批量扫描**：用户给多个 JD 时，逐个评估后输出排序表（按评分降序），
  标出"建议优先投递 Top 3"。
- **跟进节奏**：已投 5-7 天无回复 → 生成一封简短跟进邮件草稿
  （不代发，只给草稿）；面试后 24h 内发感谢信草稿。

---

## 4. 面试准备与复盘

- **准备**：基于 JD 和公司信息生成——
  - 自我介绍（1 分钟版，突出与 JD 的映射）
  - 必问问题预测 + 你的回答要点（STAR 结构）
  - 你要问面试官的问题（3-5 个，体现思考深度）
  - 行为面试题库：领导力、冲突、失败、快节奏等场景各备 1 例
- **复盘**：面试结束后，让用户描述过程，输出复盘——
  - 答得好的 / 答得差的
  - 暴露的差距 → 转化为学习项
  - 下一轮预测与准备重点

---

## 边界

- 只提供草稿与建议，不代投递、不代发邮件、不点击提交。
- 涉及具体薪酬谈判/法律问题时，说明这超出能力范围，建议咨询专业顾问。
