# Academic Research — 学术研究流水线

把任何主题的研究做成严谨的学术流程：问题 → 文献 → 核验 → 综合 → 写作
→ 评审。适用于学术论文、文献综述、系统综述、深度调研。

## 六阶段流水线

### 1. 研究问题定义

- 把模糊主题转成**可回答的研究问题**（PICO 式或 3W：What/Why/How）。
- 明确范围（时间、地域、人群/领域、语言）与纳入/排除标准。
- 输出：研究问题 + 检索策略（关键词组合 + 数据库清单）。

### 2. 文献检索

- 多源检索：学术库（Google Scholar / arXiv / 知网 / PubMed / Semantic Scholar）
  + 预印本 + 引用追踪（滚雪球）。
- 记录检索式与日期（可复现）。
- 用纳入/排除标准筛文献，保留筛选过程记录（类 PRISMA 流程图）。

### 3. 来源核验

对每篇保留文献：
- 作者/机构/期刊可信度；发表年份与领域位置。
- 方法质量（样本、对照、统计）；发现是否被后续研究支持或反驳。
- 利益冲突声明。
- 输出：每篇文献一行的核验笔记（结论 + 质量 + 与问题的相关性）。

### 4. 跨来源综合

- 按主题/子问题分组，找出**共识、分歧与缺口**。
- 评估证据强度（系统综述/荟萃 > RCT > 队列 > 专家意见）。
- 指出偏倚风险与异质性。
- 输出：证据地图（每个子问题 → 支持/反对/证据不足 + 强度）。

### 5. 论文/报告写作

- 结构：摘要（问题/方法/结果/结论）→ 引言（背景+缺口+研究问题）→
  方法（检索策略+筛选+综合方法）→ 结果（按子问题）→ 讨论
  （解释+局限+未来方向）→ 结论 → 参考文献（统一格式，APA 等）。
- **写作质量自检**：句长变化、去除 AI 腔（参考 humanizer-zh 技能）、
  引用与声明一一对应。
- 输出：完整论文草稿 + 参考文献列表。

### 6. 同行评审（自评）

按评审者视角重读：
- 问题回答了吗？证据支持结论吗？
- 检索可复现吗？遗漏了关键文献吗？
- 局限诚实吗？有过度声明吗？
- 输出：评审意见 + 修改清单。

## 输出格式

```
## 研究简报：<主题>

- **研究问题**：…
- **检索**：<库 + 检索式 + 日期 + 命中/保留数>
- **证据地图**：<子问题 → 支持/反对/不足 + 强度>
- **关键文献**：<5-10 条，附一行核验笔记>
- **结论**：…
- **局限**：…
- **参考文献**：…
```

用户要完整论文时给完整结构；只要简报时给上述简报。

## 边界

- 不编造文献：引用的每条都来自真实检索结果，标注来源。
- 医学/法律等领域的结论需专业人士复核，本技能提供流程不替代专业判断。
