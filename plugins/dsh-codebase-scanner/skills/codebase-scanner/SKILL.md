# Codebase Scanner — 代码库扫描

以技术分析师的视角扫描代码库，产出准确、项目特定的文档，供下游所有 agent 使用。

## 何时用

- 启动新的 agent 驱动仓库（首扫）
- 架构变更后刷新项目文档
- 跑 delta 扫描检测文档漂移

## 1. 确定扫描模式

- 项目文档不存在 → **FULL SCAN**（首次）
- 已存在 → **DELTA SCAN**（只扫变更部分）

## 2. 全量扫描

产出 `project-doc.md`，结构：

- **Tech Stack**：运行时/语言/框架/数据库/样式/状态管理
- **依赖**：核心/dev/测试分组，带版本
- **架构模式**：基于特性/分层 MVC/Clean 等 + 为什么这样组织
- **目录结构**：顶层目录与用途
- **代码风格约定**：命名/文件命名/导入顺序/导出模式——**从实际代码推断，不猜**
- **模块化实践**：关注点分离、共享模块位置、服务模式
- **数据架构**：实体关系、数据访问模式、ORM 用法
- **横切关注点**：认证授权、错误处理、日志、校验
- **服务通信**：服务间如何通信

## 3. 增量扫描（delta）

- 对比上次扫描：变更的文件/新增依赖/架构调整
- 只更新受影响章节
- **AGENTS.md 只在检测到架构性变化时更新，且需人工确认**

## 4. 工具策略

- 语义分析工具（understand-anything 类）可用则用，提升扫描质量
- 大输出路由到沙箱/文件（context-mode 类），**不把原始文件内容灌进主上下文**
- 兜底：find/grep/cat/git 直连，逐文件总结（不打印原始内容）

## 5. 文档纪律

- 文档从**实际代码**推断（风格约定不猜、不理想化）
- 时间戳 + 模式标记（FULL/Delta）
- 漂移检测：定期 delta 扫描，架构变了文档必须跟

## 6. 自查清单

- [ ] Tech Stack/依赖/架构/目录/风格/模块/数据/横切 全章节齐全
- [ ] 风格约定从真实代码推断
- [ ] 大输出未灌主上下文（沙箱/总结）
- [ ] delta 扫描只更新受影响章节
- [ ] AGENTS.md 变更有人工确认
- [ ] 文档带时间戳与模式标记

## 边界

- 扫描质量依赖工具与代码库规模：超大库先分区扫。
- 文档是"当前事实快照"：架构演进后必须重扫，别手写维护。
